## 議論の経緯

### 1. FM/AN目線の構造的差異

| | FM目線（批判） | AN目線（推奨） |
|---|---|---|
| 機能 | 仮説をフィルタリング | 仮説を発見・生成 |
| 性質 | 減点法、チェックリスト的 | 加点法、創造的 |
| 形式 | ルールベース（判定型） | ??? |
| 体系化 | dogma v1.0 完了 | 未着手 |

### 2. 再帰的パラドックス（2回浮上）

- 1回目: 「AN目線を**ルール化**するとFM目線と同じになるのでは？」
  → ユーザー見解: 言語化可能だが別形式（ヒューリスティクス/着眼フレームワーク等）

- 2回目: 「四択を**dogmaの分類軸**で作ったら、FM目線の空間で探索するだけでは？」
  → AI提案: 逆転の発想 — 四択A-DをFM目線の叩き台とし、E（どれも違う）の自由記述でAN目線を引き出す

### 3. dogmaフィードバックループの限界

Yからの直接的な反応:
- 「自分が書いたロジックで理詰めされる感覚があり、言い返せない」
- 「AIレポートのレビュー・検証のためにリサーチを深める必要があるが、物理的に量をまかなえない」

構造的問題: Y → AI学習 → AIがYのロジックで理詰め → Y反論不能（情報の閉鎖系）

### 4. 「着眼点のシード」大量収集アプローチ（提案段階）

従来（閉鎖系）:
```
Y のロジック → AI が学習 → AI が Y のロジックで理詰め → Y 反論不能
```

提案（開放系）:
```
AI が新仮説を大量生成 → Y が直感的に反応 → パターンを抽出
```

### 5. 収集形式の検討

| 形式 | テンポ | 情報量/問 | AN目線発見力 |
|------|--------|----------|------------|
| Yes/No | 最速 | 低(1bit) | 弱い |
| 四択+E | 速い | 高(比較判断+例外検出) | 強い |
| ◎○△×+理由 | 遅い | 最高 | 強いがスケールしない |

### 6. 二段構え設計（案、未決定）

- Phase 1（高速、15-20分）: 100問×5択、選択のみ、記述不要 → パターンマップ + E頻度分布
- Phase 2（焦点化、5分）: Eが多かった10-15問を再提示、四択再提示またはキーワード1-2語
- Phase 3（任意）: Phase 2でさらにI（まだ違う）に到達した問いだけキーワード1語

### 7. 他アナリストとの統合（方向性のみ）

- Yのレポートが短い（暗黙知が多い）→ シード収集が有効
- 他アナリストのレポートが長い（明示知が多い）→ テキスト分析で抽出可能
- 同じ仮説セットを複数アナリストに提示 → アナリスト間差異の分析
