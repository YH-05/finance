## 背景・コンテキスト

前回（disc-2026-04-10-an-seed-collection）でQ&Aシート8銘柄の生成が完了。
回答収集後の「パターン抽出」と「形式知の表現形式」について議論を実施。

## 大目的（ユーザーから提示）

アナリスト暗黙知の形式化プロジェクトの最終ゴール:
1. **優秀なアナリストたちの判断傾向をAIで再現**する
2. 再現したAIで**大量の銘柄を分析**する
3. **AN目線（推奨）とFM目線（批判）を組み合わせて**優れたパフォーマンスのポートフォリオを複数作成する

現状の課題:
- FM目線のdogma（v1.0）だけでは**銘柄推奨（=組入銘柄選定）の機能が弱い**
- dogmaは減点フィルタであり、「買うべき銘柄」のポジティブシグナルを生成しない
- **ポートフォリオ作成が難しい**

今回のYのAN目線・判断軸蓄積の位置づけ:
- **銘柄組入 → ポートフォリオ作成の判断過程で使用する**想定

## 議論の経緯

### 1. 形式知のアウトプット形式の検討

3つのアプローチを比較:

| | A. 明示的ルール化（AN版dogma） | B. 例示ベース（判断例DB） | C. ハイブリッド |
|---|---|---|---|
| やること | タグ集計→ルール抽出→KB4/KB5/KB6 | 判断例をDB蓄積→AIがin-context learningで類推 | 判断例DB（主）+傾向サマリー（副） |
| Yとの相性 | 悪い（フレームワーク非使用型） | 良い（直感型に適合） | 良い |
| パラドックス | 再燃する | 回避できる | 回避できる |
| 必要データ量 | 64例で仮説立案可能 | 64例で開始、150+例で安定 | 同左 |
| ca_strategy統合 | dogmaと同じプロンプト埋め込み | RAGで類似判断例を取得しFew-shot | 同左+傾向ガイドライン |
| 透明性 | 高い（ルールが読める） | 低い（AI内部推論依存） | 中（傾向サマリーで検証可） |

### 2. ユーザーからの問い

「属性タグ付与→ルール化」はFM dogmaと同じアプローチでは？AN版dogma構築は本当に必須か？

### 3. パラドックスの回避策

属性タグの使い方を転換:
- A案: タグ → 集計 → ルール（FM dogmaと同じ構造、パラドックス再燃）
- C案: タグ → **検索インデックス**（類似事例の検索キーとして使う、ルール化不要）

### 4. 「判断パスカタログ」の概念

ユーザーが「アナリストごとの判断経路（思考パス）のカタログ」と表現。

1銘柄分のYの回答 = 1本の「判断パス」:
- 入力: 銘柄情報 + 8つの投資仮説（根拠データ付き）
- 判断: 各仮説への納得度（どのデータに着目したか）+ BUY/SELL総合判断
- 理由: 備考欄（なぜそう判断したか）

これをアナリストごとに蓄積:
- Yのカタログ: N本の判断パス
- Zのカタログ: M本の判断パス
→ 同じ銘柄でもアナリスト個性が再現される

### 5. ca_strategyへの統合イメージ

```
新銘柄 → AI仮説生成 → カタログから類似判断パスをRAG検索
       → 「Y analyst は似た業種・仮説タイプでこう判断しました」
       → AIがYの判断傾向を推論 → ANスコア予測

FMスコア（dogma）+ ANスコア（判断パスベース）→ 複合スコア → ポートフォリオ
```

## 決定事項

| ID | 内容 | コンテキスト |
|----|------|------------|
| dec-2026-04-10-012 | AN目線の形式知は「判断パスカタログ + 類似事例検索（RAG）」方式で構築する | AN版dogma（明示的ルール化）は必須ではない。Yが直感型アナリストであり、ルール化はFM目線と同じパラドックスに陥るため |
| dec-2026-04-10-013 | 判断パスカタログ = アナリストごとの判断経路（入力→各仮説への納得度→結論）のデータベース | 「思考パスのカタログ」としてアナリストの判断傾向を蓄積する |
| dec-2026-04-10-014 | 属性タグはルール化のためではなく、類似事例検索のインデックスとして使用する | パラドックス回避: タグは検索キーであり、ルールの条件部ではない |
| dec-2026-04-10-015 | 最終ゴール = AN+FMの複合スコアでポートフォリオ構築。判断パスカタログはca_strategyのスコアリングステップに統合する | FM目線のみでは銘柄推奨機能が弱く、ポートフォリオ作成が困難 |
