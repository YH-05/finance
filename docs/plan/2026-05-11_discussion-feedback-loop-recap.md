**重要な認識追加**: 当初の判断パスカタログ設計では AN Q&A が主入力源だったが、MCO/LRCX 等の既存 FM フィードバックも判断パスカタログの**等価な入力**として扱える可能性が浮上。

### 4. MCO/LRCX フィードバックから抽出された Y の判断スタイル

判断パスカタログの**属性タグ設計に直結する観察**として以下を整理。

| # | パターン | 内容 |
|---|---|---|
| OBS-1 | 数値より論理整合性 | 定量データ（クロスセル 2 割、維持率 93%）ではなく**要素の重要性・論理整合性**で納得度が決まる |
| OBS-2 | 保守的予想バイアス棄却 | 「保守的だから確度高い」を棄却。最適推量からのズレは確度ではない |
| OBS-3 | BUY 援護的バイアス検出 | 「達成しやすい予想にしておく」セルサイドの慣習を評価しない |
| OBS-4 | 構造分解と加重平均 | 事業セグメント別の構成比で主張を希薄化（例: 格付け 50% × 寡占 90% + 非格付け 50% × 70%） |
| OBS-5 | ダブルカウントリスク | 主張間の独立性を厳しく評価。原因と結果の主張を分けて評価 |

### 5. SELL 判断の規律（Y からの提示、LRCX フィードバックより）

Y 自身がフィードバック内で提示した SELL 判断 3 軸:
1. **期初投資前提の崩壊**
2. **バリューの過剰上昇**
3. **他の有望銘柄への入れ替え**

→ 「**BUY 前提のどの部分を取り下げ、何を追加したか**」が判断パスの**差分構造**となる。

### 6. Y 自身のメタ反省（プロジェクトの隠れた目的）

LRCX フィードバックで Y が記述した自己批評:
- これまでの SELL は損切りが多く、**SELL 後もインデックスを超過**する傾向 → SELL 判断は奏功せず
- 担当者変更で SELL 推奨が増える → SELL の動機（十分な再考？好き嫌い？面倒さ？自己アピール？）への自問
- → **AI で SELL 判断の規律を客観化したい**という潜在ニーズが浮上

### 7. 認識合わせが必要な 4 論点（次回議論に持ち越し）

| ID | 論点 | 現在の理解 |
|---|---|---|
| A | FM フィードバック (MCO/LRCX 等) の位置づけ | 判断パスカタログの**等価な入力**として扱うか、別カタログか未決 |
| B | SELL 判断規律のパス表現 | 単一時点スナップショットか、BUY→SELL の**差分パス**として時系列モデル化するか未決 |
| C | 論理整合性の評価軸 | 属性タグに「論理構造の品質」を入れるか、仮説テキストの意味埋め込みで暗黙的に扱うか未決 |
| D | Y 回答収集の運用方針 | Y への提示プロセスを継続するか、回答済み銘柄で先行設計に進むか未決 |
