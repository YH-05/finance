デレーティング（de-rating）とリレーティング（re-rating）は、株式のバリュエーション倍率（主にPER、PBR、EV/EBITDA等）の変化を指す用語である。利益やキャッシュフローといったファンダメンタルズの変化ではなく、市場が同一のファンダメンタルズに対して支払う「倍率」そのものが変化する現象を表す。

## 定義

**デレーティング**: バリュエーション倍率の低下を指す。例えばPERが20倍から15倍に縮小する状態。利益が一定でも倍率が縮小すれば株価は下落する。

**リレーティング**: バリュエーション倍率の上昇を指す。PERが15倍から20倍に拡大する状態。利益が一定でも倍率が拡大すれば株価は上昇する。

## 株価変化の分解

株価リターンは概念的に以下に分解できる。

```
株価リターン ≈ EPS成長率 + 倍率変化率(re/de-rating) + 配当利回り
```

この分解は、リターンのうちどの程度がファンダメンタルズ（利益成長）由来で、どの程度が市場のセンチメントや期待（倍率変化）由来かを峻別する点で、定量・定性統合の観点から重要である。

|要因|デレーティング|リレーティング|
|---|---|---|
|倍率の方向|縮小|拡大|
|株価への寄与（利益一定時）|マイナス|プラス|
|典型的な背景|成長期待の剥落、リスクプレミアム上昇、レジーム悪化|成長期待の回復、リスクプレミアム低下、構造的改善の織り込み|

## ドライバー

倍率変化は、大別して以下の要因によって生じる。

- **成長期待の変化**: 将来の利益成長率（g）に対する市場見通しの修正。Gordon成長モデルの枠組みでは、フォワードPER ≈ 1 / (r − g) に近似でき、gの低下またはr（要求リターン）の上昇が同時にデレーティングを引き起こす。
- **割引率・リスクプレミアムの変化**: 金利上昇やエクイティリスクプレミアム拡大は分母のrを引き上げ、機械的にデレーティングを誘発する。マクロレジーム判別と直結する。
- **クオリティ・収益安定性の再評価**: ROIC水準、利益の持続性、資本配分の質に対する市場の認識変化。
- **構造変化**: セクターの競争環境、規制、技術代替等による恒久的な期待修正。

## ファクター投資における含意

バリュー戦略の長期不振（過去7-8年）の一因として、バリュー株の持続的デレーティングと、グロース・クオリティ株の持続的リレーティングという倍率分化が挙げられる。すなわち、安価な銘柄がさらに安価になり（valueトラップ化）、高倍率銘柄がさらに倍率を拡大させた構造である。

この観点で注意すべき点は以下である。

1. **平均回帰の前提への懐疑**: バリュー戦略は暗黙に倍率の平均回帰（デレーティングしたものはいずれリレーティングする）を仮定するが、構造変化が生じている場合この前提は崩れる。相関と因果の区別の問題に帰着する。
2. **倍率変化の因果構造**: デレーティングが「割安化（投資機会）」なのか「ファンダメンタルズ劣化の先行シグナル」なのかは、Colliderやconfounderを含む因果構造の検討を要する。倍率低下を単純に回帰のシグナルとして扱うとFactor Mirageを生む可能性がある。
3. **アトリビューション**: ポートフォリオの超過リターンを利益成長要因と倍率変化要因に分解することで、ファクターエクスポージャーの実態（真の割安性の捕捉か、単なるモメンタムの裏返しか）を検証できる。

実務上は、リレーティング/デレーティングをリターンの「説明変数」としてだけでなく、過去のリターンが倍率拡大に過度に依存していた場合の将来リターン持続性に対する「守りの指標」としても活用できる。
## 分解軸の違い

### リターン分解（株価リターンのファンダメンタル分解）

前述の分解は、株価リターンを**会計恒等式に基づく乗法的（multiplicative）構造**として捉える。

```
P = EPS × PER

⇒ (1 + R_price) = (1 + g_EPS) × (1 + Δ_multiple) × (配当寄与)
```

対数を取れば加法分解になる。

```
ln(1 + R) ≈ Δln(EPS) + Δln(PER) + 配当利回り
```

ここでの分解軸は「価格を構成する会計的・評価的コンポーネント」である。すなわち、**単一銘柄（または集計したインデックス）について、その価格がどの構成要素から生じたか**を恒等式的に分解する。誤差項は理論上ゼロ（クロス項を除けば恒等式）である。

### マルチファクターモデルの分解

ファクターモデルは、**横断面（cross-section）の共分散構造に基づく線形回帰モデル**である。

```
R_i = α_i + Σ_k β_{i,k} F_k + ε_i
```

ポートフォリオレベルでは以下に分解される。

```
R_p = Σ_k (β_{p,k} × F_k)  [ファクター寄与]
     + Σ_i (w_i × α_i)      [銘柄選択 / 特異リターン]
     + ε_p                  [残差]
```

ここでの分解軸は「**共通のリスク源（systematic risk factors）への感応度**」である。価格の構成要素ではなく、**複数銘柄間でリターンを動かす共通要因への曝露**を抽出する。

## 本質的な相違の理由

|観点|リターン分解|ファクターモデル分解|
|---|---|---|
|数学的構造|会計恒等式（決定論的）|統計的回帰（確率モデル、誤差項を含む）|
|分解の次元|時系列・単一資産内部|横断面・資産間の共変動|
|分解対象|価格を生むコンポーネント（EPS, 倍率, 配当）|共通リスクファクターへの感応度（β）|
|de/re-ratingの位置|倍率変化として**明示的な一項**|通常、独立した項として現れない（valueやmomentum等に吸収される）|
|残差の意味|クロス項のみ（ほぼゼロ）|特異リターン ε（モデルで説明されない部分）|
|推定の要否|不要（観測値から直接計算）|要（回帰、共分散行列の推定）|

決定的な違いは、リターン分解が**恒等式**であるのに対し、ファクター分解が**推定を伴う統計モデル**である点である。前者は誤差を持たず一意に定まるが、後者はファクターの定義・推定手法・ユニバースに依存し、同一リターンが異なるファクター構成に分解されうる。

## de/re-ratingがファクターモデルで「見えにくい」理由

これが両者を直接対応させられない核心である。

1. **倍率変化はファクターモデルでは独立項として現れない。** PERの拡大・縮小という現象は、ファクターモデル上では複数のファクター曝露の混合として吸収される。例えば、バリュー株のデレーティングは「valueファクターのマイナスリターン」として現れ、グロース株のリレーティングは「成長・クオリティ・モメンタムファクターのプラスリターン」に分散して現れる。倍率変化そのものを取り出す項は標準的なモデルには存在しない。
    
2. **ファクターリターン自体が倍率変化と利益成長の混合物である。** 例えばHML（value）ファクターのリターンを時系列分解すると、その大半が構成銘柄群の**相対的な倍率変化（リレーティング/デレーティングのスプレッド）**で説明される局面がある。つまりファクターリターンの内部に倍率変化が埋め込まれているが、モデルの出力レベルでは分離されない。
    
3. **因果構造の観点での帰結。** ファクター曝露（β）は共変動の測定であって、価格形成の因果メカニズムを記述しない。「valueファクターが負のリターンを生んだ」という記述と、「割安銘柄群が持続的にデレーティングした」という記述は、同一現象の統計的記述と機構的記述であり、後者の方が因果仮説（平均回帰の崩壊、構造変化）に接続しやすい。ファクターモデル単独では、デレーティングが一時的なミスプライシングか恒久的な再評価かを判別できない。
    

## 実務的な統合

両分解は競合ではなく補完関係にある。推奨される使い分けは以下である。

- **ファクターモデル**: ポートフォリオの**リスク要因への曝露管理**とリスク予算配分。横断面の相対パフォーマンス源泉の特定。
- **リターン分解**: 銘柄・セクター・ポートフォリオレベルでの**リターンの質の検証**。具体的には、超過リターンが利益成長（ファンダメンタルズ）由来か倍率拡大（センチメント・期待）由来かを峻別し、リターンの持続可能性を評価する。

統合的な分析としては、ファクターリターン（例: HML）をさらに「構成銘柄の利益成長スプレッド」と「倍率変化スプレッド」に二次分解する手法が有効である。これにより、「バリュー戦略の不振は割安銘柄の利益が伸びなかったためか、それとも倍率がデレーティングし続けたためか」という因果仮説の切り分けが可能になり、平均回帰前提の妥当性検証に直結する。後者が支配的であれば、それは構造変化（恒久的再評価）の可能性を示唆し、単純なvalue戦略の有効性に対する批判的評価の根拠となる。
