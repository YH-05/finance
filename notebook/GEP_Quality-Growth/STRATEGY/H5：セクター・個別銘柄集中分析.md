# H5: セクター/個別銘柄集中(構成効果)の分析手法

## 1. 問題の構造化

H5の核心は、観測された「クオリティ劣後」が以下のどちらに起因するかの切り分けである。

- **ファクター固有効果**: クオリティという特性そのものが、銘柄選好を通じて全セクター横断的に劣後を生んでいる
- **構成効果（composition effect）**: 特定セクターや少数大型銘柄の不振が、クオリティ・ポートフォリオの偏った構成を経由してファクター・リターン全体を引き下げている

因果構造の観点では、これは**セクターが交絡因子（confounder）として作用する**典型例である。前回議論したFork構造に対応する。

```
        セクター(Z: 例 テック/ヘルスケア)
       ↙                        ↘
クオリティ・スコア(X)        セクター固有リターン(Y)
```

クオリティ銘柄が特定セクターに構造的に偏在し、かつそのセクターが特定期間に特異なリターンを示すと、「クオリティ→リターン」の見かけの関係にセクター効果が混入する。したがってH5の検証は、**セクター効果の統制（除去）後にクオリティ効果が残るか**を問うことに帰着する。

---

## 2. 分析手法の全体像

3つのアプローチを難易度・データ要件順に提示する。

|手法|データ要件|出力|識別できるもの|
|---|---|---|---|
|(A) セクター中立版との差分|MSCI通常版・セクター中立版の指数リターン|構成効果の総量|セクター集中効果の有無|
|(B) Brinson型寄与度分解|セクター別L/Sリターン・ウェイト|セクター別寄与|どのセクターが主因か|
|(C) 個別銘柄レベル分解|構成銘柄ウェイト・個別リターン|銘柄別寄与|Mag7等の集中効果|

## 3. 手法A: セクター中立版との差分分析

### 3.1 原理

MSCIは多くのファクター指数で**通常版（sector-tilted）**と**セクター中立版（sector-neutral）**の両方を提供している。セクター中立版は、各セクターのウェイトをベンチマーク（親指数）と一致させた上で、セクター**内**でのみクオリティ・チルトをかける。したがって両者の差分が構成効果を表す。

$$ R_{\text{通常}} = R_{\text{セクター中立}} + R_{\text{セクター配分効果}} $$

- $R_{\text{セクター中立}}$: 純粋な銘柄選択効果（セクター内でのクオリティ効果）
- $R_{\text{セクター配分効果}}$: セクター・ウェイトの偏りに起因する効果 = **構成効果（H5）**

### 3.2 判定ロジック

```
ケース1: 通常版が劣後、セクター中立版も同程度劣後
  → 構成効果は小さい。クオリティ固有の劣後(H5は棄却寄り)

ケース2: 通常版が劣後、セクター中立版は劣後せず
  → 劣後の大半がセクター配分効果。H5支持。
    クオリティ特性そのものでなくセクター偏在が主因
```

### 3.3 該当指数

検証対象として、以下の指数ペアの取得を推奨する。

- `MSCI World Quality Index`（通常版）
- `MSCI World Quality Sector Neutral Index`（セクター中立版）

加えてロングオンリーでなくL/Sで見たい場合は、親指数（`MSCI World`）に対する超過リターンを両版で計算し、その差分を取る。

### 3.4 実装

```python
import pandas as pd
import numpy as np
import statsmodels.api as sm

def decompose_composition_effect(
    r_standard: pd.Series,      # 通常版クオリティ指数リターン
    r_neutral: pd.Series,       # セクター中立版リターン
    r_parent: pd.Series,        # 親指数(MSCI World)リターン
    regime_split: str = "2023-01-01"
) -> pd.DataFrame:
    """
    通常版・セクター中立版の対親指数超過リターンを分解し、
    セクター配分効果(構成効果)をレジーム別に算出する。
    """
    # 対親指数の超過リターン(=ロングオンリーのアクティブ効果)
    active_std = r_standard - r_parent
    active_neu = r_neutral - r_parent

    # 構成効果 = 通常版アクティブ - セクター中立版アクティブ
    composition = active_std - active_neu  # セクター配分効果
    selection   = active_neu               # 銘柄選択効果(セクター内)

    df = pd.DataFrame({
        "active_total": active_std,
        "selection": selection,       # セクター内クオリティ効果
        "composition": composition,   # セクター配分効果(H5)
    })

    # レジーム別の累積寄与
    pre  = df.loc[:regime_split]
    post = df.loc[regime_split:]

    summary = pd.DataFrame({
        "pre_2023_ann":  pre.add(1).prod() ** (252/len(pre)) - 1,
        "post_2023_ann": post.add(1).prod() ** (252/len(post)) - 1,
    })
    summary["delta"] = summary["post_2023_ann"] - summary["pre_2023_ann"]
    return df, summary

# 解釈:
# summary.loc["composition", "post_2023_ann"] が大きく負
#   → 2023年以降の劣後はセクター配分効果が主因 (H5支持)
# summary.loc["selection", "post_2023_ann"] が大きく負
#   → セクター内のクオリティ選択そのものが劣後 (H5棄却寄り)
```

### 3.5 留意点

セクター中立化は**セクターという交絡因子の統制**に該当し因果的に正当化される。ただし以下に注意する。

- **過剰統制の懸念**: クオリティとセクターに真の因果経路（クオリティが高い企業は特定産業に集まる構造的理由）がある場合、セクター中立化はクオリティ効果の一部を不当に除去する。これはセクターを純粋なconfounderと見なすか、一部mediatorと見なすかの問題。経済理論に基づき、セクター偏在が「クオリティの本質」か「測定上の偶発」かを事前に判断する。
- MSCIのセクター分類はGICSベース。セクター粒度（11セクター vs 24業種グループ）で結果が変わりうるため、複数粒度で頑健性を確認する。

## 4. 手法B: Brinson型寄与度分解

### 4.1 原理

セクター別のウェイトとリターンが取得できる場合、運用業界標準の**Brinson-Fachler分解**でアクティブ・リターンをセクター別に帰属させる。各セクターのアクティブ寄与を、配分効果（allocation）と選択効果（selection）に分解する。

セクター $i$ について、

$$ \underbrace{(w_i^P - w_i^B)(R_i^B - R^B)}_{\text{配分効果}} + \underbrace{w_i^B(R_i^P - R_i^B)}_{\text{選択効果}} + \underbrace{(w_i^P - w_i^B)(R_i^P - R_i^B)}_{\text{交互作用}} $$

- $w_i^P, w_i^B$: ポートフォリオ・ベンチマークのセクター $i$ ウェイト
- $R_i^P, R_i^B$: ポートフォリオ・ベンチマークのセクター $i$ リターン
- $R^B$: ベンチマーク全体リターン

### 4.2 H5への適用

L/Sポートフォリオの場合は、セクター別のロング・ショート両サイドのリターンを取り、セクター別L/S寄与を直接計算する方が直感的である。

$$ R_{\text{quality L/S}} = \sum_i \left( w_i^{\text{L}} R_i^{\text{L}} - w_i^{\text{S}} R_i^{\text{S}} \right) $$

各セクター $i$ の項 $\left( w_i^{\text{L}} R_i^{\text{L}} - w_i^{\text{S}} R_i^{\text{S}} \right)$ がそのセクターのクオリティ劣後への寄与となる。

### 4.3 実装

```python
def brinson_sector_attribution(
    w_port: pd.DataFrame,    # index=date, columns=sector, ポートフォリオ・ウェイト
    w_bench: pd.DataFrame,   # ベンチマーク・ウェイト
    r_sector: pd.DataFrame,  # セクター別リターン (port視点)
    r_bench_sector: pd.DataFrame,  # セクター別リターン (bench視点)
    r_bench_total: pd.Series       # ベンチマーク全体リターン
) -> pd.DataFrame:
    """
    Brinson-Fachler分解。セクター別の配分・選択・交互作用効果を返す。
    """
    allocation  = (w_port - w_bench) * (r_bench_sector.sub(r_bench_total, axis=0))
    selection   = w_bench * (r_sector - r_bench_sector)
    interaction = (w_port - w_bench) * (r_sector - r_bench_sector)

    result = pd.concat({
        "allocation": allocation,
        "selection": selection,
        "interaction": interaction,
    }, axis=1)
    return result

def post2023_sector_contribution(result: pd.DataFrame,
                                  split: str = "2023-01-01") -> pd.DataFrame:
    """
    2023年以降の各セクター・各効果の累積寄与をランキング。
    最も劣後に寄与したセクターを特定する。
    """
    post = result.loc[split:]
    cum = post.sum(axis=0)  # 各(効果, セクター)の累積
    tbl = cum.unstack(level=0)  # rows=sector, cols=効果
    tbl["total"] = tbl.sum(axis=1)
    return tbl.sort_values("total")  # 最も劣後に寄与したセクターが上位
```

### 4.4 期待される診断

```
出力例(2023年以降 累積寄与, %):

セクター          配分    選択    交互  合計
情報技術         -3.2   -1.1   -0.4  -4.7   ← 主因
ヘルスケア       -1.8   -0.6   -0.2  -2.6
生活必需品       -1.2   -0.3   -0.1  -1.6
その他8セクター   +0.5   +0.3    0.0  +0.8
─────────────────────────────────
合計             -5.7   -1.7   -0.7  -8.1

解釈:
- 劣後の大半(-5.7)が配分効果 → H5支持。特定セクター集中が主因
- 情報技術セクターが単独で約6割を説明 → さらに手法Cで銘柄分解
- 選択効果が小さい → セクター内のクオリティ選別は機能している
```

## 5. 手法C: 個別銘柄レベル分解(Mag7集中効果)

### 5.1 原理

「Magnificent 7がクオリティ・ロングに入っているか否か」という論点は、構成銘柄ウェイトが取得できれば直接検証できる。手法はシンプルな**leave-one-out（除外）分析**と**寄与度分解**である。

### 5.2 寄与度分解

各銘柄 $j$ のポートフォリオ・リターンへの寄与は $w_j R_j$。Mag7群の寄与を集計し、全体に占める割合を見る。

```python
def stock_level_contribution(
    weights: pd.DataFrame,   # index=date, columns=ticker
    returns: pd.DataFrame,   # 個別銘柄リターン
    target_group: list,      # 例: Mag7 = ['AAPL','MSFT','NVDA',...]
    split: str = "2023-01-01"
) -> dict:
    """
    特定銘柄群の寄与と、除外した場合の反実仮想リターンを算出。
    """
    contrib = weights * returns          # 各銘柄の日次寄与
    post = contrib.loc[split:]

    total_ret = post.sum(axis=1)         # ポート全体
    group_ret = post[target_group].sum(axis=1)   # Mag7群の寄与
    ex_group  = total_ret - group_ret    # Mag7除外時(反実仮想)

    return {
        "total_cum":     (1 + total_ret).prod() - 1,
        "group_cum":     group_ret.sum(),                # Mag7寄与
        "ex_group_cum":  (1 + ex_group).prod() - 1,      # 反実仮想
        "group_share":   group_ret.sum() / total_ret.sum(),
    }

# 解釈:
# ex_group_cum が大幅に改善(劣後が消える)
#   → 劣後はMag7のクオリティ・ロング/ショート配置に起因
#   → ファクター全体の問題でない (H5を強く支持)
```

### 5.3 反実仮想（counterfactual）の位置づけ

Mag7を除外した「もしMag7がポートフォリオになかったら」というシナリオは、ユーザーの関心領域である**反実仮想分析**の素朴な実装である。ただしこれは厳密なdo-calculusではなく単純な再集計（partial counterfactual）であり、Mag7除外がポートフォリオ全体のリスク特性に与える二次効果は捉えない点に留意する。

### 5.4 データ制約への対処

> 「個別銘柄レベルは制約で困難だが、セクター・レベルなら指数データで近似可能」

という前回の留保について、Mag7に限れば制約は緩い。Mag7は全て大型・高流動・開示充実銘柄であり、以下で近似取得が可能。

- **ウェイト**: MSCI指数の月次構成開示（上位構成銘柄は公開される）、またはiShares等のETF日次保有データ（`ISIN`ベースで取得可能）
- **リターン**: `yfinance` / `Polygon.io` で日次取得
- **クオリティ・スコア所属**: 自前でAQR QMJ型スコアを構築し、Mag7各銘柄がロング群（上位分位）かショート群かを判定。これにより「Mag7がクオリティ・ロングに入っているか」を内生的に確認できる

## 6. 統合ワークフローと判定

3手法を組み合わせた検証順序を示す。

```
Step 1: 手法A (セクター中立版差分)
  → 構成効果の総量を把握。H5の大枠を判定
     構成効果が小さい → H5棄却、他仮説(H1/H3/H7)へ
     構成効果が大きい → Step 2へ

Step 2: 手法B (Brinson分解)
  → どのセクターが劣後を駆動したか特定
     情報技術が主因 → Step 3へ(Mag7の可能性大)
     ヘルスケア/生活必需品が主因 → ディフェンシブ・セクターの
        金利感応(H0)・ローテーション(H2)との接続を検討

Step 3: 手法C (Mag7銘柄分解)
  → 反実仮想で集中効果を定量化
     Mag7除外で劣後消失 → 構成効果が確定。H5支持
```

### 判定マトリクス

|手法Aの構成効果|手法Bの集中度|手法CのMag7寄与|結論|運用示唆|
|---|---|---|---|---|
|大|単一セクター集中|大|H5支持（構成効果主因）|ファクター放棄でなくセクター/銘柄分散・ウェイト上限導入|
|大|分散|小|部分的構成効果|セクター中立版への切替検討|
|小|—|—|H5棄却|クオリティ固有劣後。H1/H3/H7を精査|

## 7. 他仮説との関係（過剰解釈の回避）

H5の検証で最も陥りやすい誤りは、構成効果を検出して「劣後はセクター集中のせいであり、クオリティ・ファクター自体は健全」と早期結論することである。批判的思考の観点から以下を確認する。

- **H5とH7の交絡**: 特定セクター（ヘルスケア、生活必需品=ディフェンシブ）の不振が「セクター集中」に見えても、その背後にマクロ・レジーム（景気サイクル局面、リスクオン・ローテーション）という上流要因があれば、真因はH7である。手法Bでディフェンシブ・セクターが主因と出た場合は、H7のマクロ統制と必ず突き合わせる。
- **H5とH4の交絡**: そもそもセクター・ウェイトが時系列で変質していれば（H4: 構成の変質）、ある時点のセクター集中は「クオリティの定義変化」の結果かもしれない。手法Bは各時点のウェイトを所与とするため、ウェイト推移そのものの分析（H4）と併用する。

H5は単独で結論を出すものでなく、構成効果の寄与を分離した上で、残差をH1/H3/H7に引き渡す中間段階と位置づけるのが正しい。
