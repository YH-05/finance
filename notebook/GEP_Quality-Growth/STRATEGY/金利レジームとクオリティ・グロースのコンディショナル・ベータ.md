

## 1. クオリティ・グロースがロング・デュレーション資産である理由

### 1.1 配当割引モデル（DDM）からの導出

株式価値を割引配当の現在価値として表現すると：

$$P = \sum_{t=1}^{\infty} \frac{CF_t}{(1+r)^t}, \quad r = r_f + \text{ERP}$$

ここで `r_f` は実質無リスク金利、ERP はエクイティ・リスクプレミアム。デュレーション（金利感応度）は、キャッシュフローの時間的重心で決まる。

**デュレーションの定義**（Macaulay 型の株式版）：

$$D = -\frac{1}{P}\frac{\partial P}{\partial r} = \frac{\sum_{t} t \cdot \frac{CF_t}{(1+r)^t}}{\sum_{t} \frac{CF_t}{(1+r)^t}}$$

グロース銘柄はキャッシュフローが将来に大きく偏在するため、加重平均時点 `t` が遠い。すなわち **D が大きい = ロング・デュレーション**。逆にバリュー銘柄は近い将来のキャッシュフロー比率が高く、ショート・デュレーション。

### 1.2 金利上昇の非対称的影響

`r` が `Δr` 上昇したとき、価格変化は近似的に：

$$\frac{\Delta P}{P} \approx -D \cdot \Delta r$$

D が大きいグロース銘柄ほど、同一の `Δr` に対して価格下落が大きい。これが「実質金利上昇局面でロング・デュレーション資産が構造的に劣後する」メカニズムの核心である。

### 1.3 クオリティとグロースの区別に関する注意

ここで概念的な精緻化が必要である。**クオリティ（高ROIC・低レバレッジ・高収益安定性）とグロース（高売上/利益成長期待）は別物**であり、デュレーション論理が直接当てはまるのはグロースの方である。

- **グロース**: キャッシュフローが将来偏在 → 高デュレーション → 金利感応度が高いことは理論的に明快。
- **クオリティ**: 必ずしも高デュレーションではない。むしろ安定収益・高フリーキャッシュフローを持つ「ボンドプロキシ」的性質を持つ場合があり、これは別の経路で金利に感応する。

2010年代後半以降、大型テック（GAFAM等）が「高クオリティかつ高グロース」の両面を持つため両者が混同されやすいが、**ファクター設計時には分離すべき**。**仮説検証では「クオリティ・ファクター」と「グロース・ファクター」を別々に回帰にかけ、デュレーション論理がどちらに強く効くかを実証的に確認することが必要。**

## 2. 検証手法の詳細

### 2.1 ローリング・ベータ推定

提示された基本回帰式：

$$R_{\text{quality},t} = \alpha + \beta_1 \Delta\text{RealRate}_t + \beta_2 \Delta\text{TermSpread}_t + \beta_3 \text{MktRf}_t + \varepsilon_t$$

各変数の定義と論点：

|変数|定義|データソース|論点|
|---|---|---|---|
|`R_quality`|クオリティ・ファクターの超過リターン|AQR Data Library (QMJ), Fama-French|自前構築か既製か|
|`ΔRealRate`|10年TIPS利回り変化|FRED: `DFII10`|レベルか変化か（後述）|
|`ΔTermSpread`|期間スプレッド変化（10Y-2Y等）|FRED: `T10Y2Y`|名目か実質か|
|`MktRf`|市場超過リターン|Fama-French|直交化の要否|

**ローリング・ウィンドウの設計**：

- ウィンドウ長：126営業日（半年）〜252営業日（1年）が一般的。短いと推定ノイズ、長いとレジーム変化の検出が遅れるトレードオフ。
- ステップ：日次でローリングし、`β1` の時系列をプロットする。2022-2023年の利上げ局面で `β1` が有意に負方向に振れていれば仮説を支持。

### 2.2 レジーム分割回帰

金利環境を外生的に2レジームに分割し、ダミー変数で交差項を入れる：

$$R_{\text{quality},t} = \alpha + (\beta_1 + \gamma_1 D_t)\Delta\text{RealRate}_t + \beta_2 \Delta\text{TermSpread}_t + \beta_3 \text{MktRf}_t + \varepsilon_t$$

`D_t = 1`（金利上昇局面）、`0`（低下局面）。`γ1` の有意性が「レジーム依存性（コンディショナル・ベータ）」の直接的検定となる。

**レジーム定義の方法**（外生分割の選択肢）：

1. 実質金利の3ヶ月移動平均の符号
2. FOMC の利上げ/利下げサイクル（政策金利の方向）
3. 実質金利が過去Nヶ月で上位/下位四分位

### 2.3 マルコフ・レジームスイッチングモデル

外生的にレジームを定義せず、データ自身にレジームを推定させる内生的アプローチ。Hamilton (1989) のフレームワーク：

$$R_{\text{quality},t} = \alpha_{S_t} + \beta_{1,S_t}\Delta\text{RealRate}_t + \dots + \varepsilon_t, \quad \varepsilon_t \sim N(0, \sigma_{S_t}^2)$$

潜在状態 `S_t ∈ {1,2}` が遷移確率行列 `P` に従う：

$$P = \begin{pmatrix} p_{11} & 1-p_{11} \ 1-p_{22} & p_{22} \end{pmatrix}$$

**利点**：レジーム転換点を事後的にスムージング確率として可視化でき、外生分割の恣意性を回避できる。**欠点**：レジーム数の選定、初期値依存、小標本での収束問題。Python では `statsmodels.tsa.regime_switching.markov_regression` で実装可能。

## 3. 計量経済学上の重大な論点

ユーザーの因果推論への関心（López de Prado 的厳密性）を踏まえ、見落とすと結論が崩れる論点を列挙する。

### 3.1 レベル vs 変化（定常性）

金利「レベル」は非定常（単位根を持つ）可能性が高い。**リターン（定常）を非定常変数に回帰すると見せかけの回帰（spurious regression）**が生じる。原則として金利は**変化（Δ）**で入れる。ADF検定・KPSS検定で定常性を事前確認すべき。

### 3.2 名目金利 = 実質金利 + 期待インフレ

名目金利変化には実質金利成分とインフレ期待成分（ブレークイーブン）が混在する。デュレーション論理が効くのは**実質金利**経路。フィッシャー分解：

$$\Delta i_{\text{nominal}} = \Delta r_{\text{real}} + \Delta \pi^e$$

`ΔRealRate`（TIPS）を使うのは正しいが、`ΔBreakeven` も別ファクターとして加え、両者の係数を比較すると因果経路の分離ができる。

### 3.3 内生性とColliderリスク

これがユーザーの関心に最も直結する論点。`MktRf` を統制変数に入れる際の問題：

- **市場リターン自体が金利に感応する**。`MktRf` は `ΔRealRate → 株式市場 → R_quality` という経路上の**中間変数（mediator）**かもしれない。これを統制すると、金利のクオリティへの**総効果の一部を吸収してしまう**。
- 逆に、市場と無関係な金利の直接効果だけを見たいなら統制は妥当。**何を推定したいか（総効果 vs 直接効果）を DAG で先に明示**してから統制変数を決めるべき。

DAG の素描例：

```
ΔRealRate ──────────────→ R_quality
     │                          ↑
     └──→ MktRf ────────────────┘
            ↑
        (他のマクロ要因 = 交絡候補)
```

`MktRf` が mediator なら統制で直接効果のみ、交絡なら統制で因果効果を識別、という分岐がある。Collider バイアスの懸念は、両方向の矢印が `MktRf` に入る変数を不用意に統制した場合に生じる。

### 3.4 系列相関・分散不均一

リターン回帰では誤差項に系列相関とヘテロスケダスティシティが残りやすい。**Newey-West（HAC）標準誤差**を用いて `t` 値を補正する。これを怠ると `γ1` の有意性を過大評価する。

### 3.5 多重検定とp-hacking

ウィンドウ長、レジーム定義、ラグ構造など複数の仕様を試すと、偶然の有意結果が出る。ユーザーの志向する **Deflated Sharpe Ratio** や、仕様の事前登録（pre-registration）的な規律が望ましい。

## 4. 実装コード骨子（Python）

```python
import pandas as pd, numpy as np
import statsmodels.api as sm
from statsmodels.tsa.regime_switching.markov_regression import MarkovRegression
from pandas_datareader import data as web

# --- データ取得 ---
# 実質金利（10Y TIPS）、期間スプレッド
real_rate = web.DataReader('DFII10', 'fred', start, end)        # 10Y TIPS
term_spread = web.DataReader('T10Y2Y', 'fred', start, end)      # 10Y-2Y
# クオリティ・ファクターは AQR QMJ または自前構築（ROIC, gross profitability 等）

df = pd.concat([R_quality, real_rate, term_spread, MktRf], axis=1).dropna()
df['d_real']  = df['DFII10'].diff()
df['d_term']  = df['T10Y2Y'].diff()
df = df.dropna()

# --- 定常性チェック ---
from statsmodels.tsa.stattools import adfuller
for col in ['d_real','d_term','R_quality']:
    print(col, adfuller(df[col])[1])  # p値 < 0.05 で定常

# --- ローリング・ベータ ---
def rolling_beta(df, window=252):
    betas = []
    for i in range(window, len(df)):
        sub = df.iloc[i-window:i]
        X = sm.add_constant(sub[['d_real','d_term','MktRf']])
        m = sm.OLS(sub['R_quality'], X).fit(cov_type='HAC',
                                            cov_kwds={'maxlags':5})
        betas.append((sub.index[-1], m.params['d_real']))
    return pd.DataFrame(betas, columns=['date','beta_real']).set_index('date')

beta_ts = rolling_beta(df)

# --- レジーム分割回帰（金利上昇ダミー）---
df['regime_up'] = (df['DFII10'].diff(63) > 0).astype(int)  # 3M上昇局面
df['interact']  = df['regime_up'] * df['d_real']
X = sm.add_constant(df[['d_real','interact','d_term','MktRf']])
reg = sm.OLS(df['R_quality'], X).fit(cov_type='HAC', cov_kwds={'maxlags':5})
print(reg.summary())   # interact の係数 = γ1 がレジーム依存性

# --- マルコフ・レジームスイッチング ---
exog = sm.add_constant(df[['d_real','d_term','MktRf']])
ms = MarkovRegression(df['R_quality'], k_regimes=2, exog=exog,
                      switching_variance=True).fit()
print(ms.summary())
smoothed = ms.smoothed_marginal_probabilities[0]  # レジーム1確率の時系列
```

## 5. 運用示唆の精緻化と批判的留意点

### 5.1 動的配分の論理

ローリング `β1` が安定的に負で、かつ金利見通しに予測力があるなら、「実質金利上昇を予想する局面でクオリティ/グロース・エクスポージャーを削減」というタイミング戦略が導出される。ただし以下の条件付き。

### 5.2 実質金利デュレーション・ヘッジ

ポートフォリオの推定 `β1`（金利感応度）を、TIPS・金利先物・スワップで相殺する。ヘッジ比率：

$$N_{\text{hedge}} = \frac{\hat{\beta}_1 \cdot \text{Portfolio Value}}{\text{DV01}_{\text{hedge instrument}}}$$

これにより金利方向に対して中立化し、純粋なファクター・アルファのみを残す設計が可能。

### 5.3 仮説に対する批判的検討（代替説明）

ユーザーの「批判的思考」「代替説明の検討」原則に従い、金利レジーム以外の劣後要因も併記する：

1. **バリュエーション平均回帰**: 2020-2021年のグロース過熱の単純な巻き戻しであり、金利は引き金にすぎない可能性。金利を統制してもバリュエーション・スプレッドが残差を説明するか検証すべき。
2. **混雑度（Comomentum）**: クオリティ/グロースへの資金集中の解消。ユーザーが関心を持つ crowding 指標との相互作用を見る価値がある。
3. **時変リスクプレミアム**: 金利「水準」が変わると ERP も変化し、デュレーション効果と分離困難。
4. **β の不安定性そのもの**: ローリング `β1` が時変であること自体が、単一の「金利レジーム」説明では不十分である証拠になりうる。

### 5.4 結論の確からしさ

この仮説は理論的に強固（デュレーション論理は頑健）だが、**「2023年以降の劣後を金利レジームで説明可能」という主張は過剰決定（overdetermined）の問題を抱える**。金利・バリュエーション・混雑度が同時に動いたため、単独要因への帰属には因果識別上の慎重さが要る。実質金利の外生的変動（例：FOMC サプライズの高頻度識別）を用いた局所的因果推論で補強することが、結論の信頼性を高める方向性として推奨される。

特に深掘りしたい論点（マルコフモデルの実装詳細、Comomentum との統合、因果識別戦略のいずれか）があれば指定されたい。
