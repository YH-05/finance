
# 提案B: レジーム別パフォーマンス分解の詳細

## 0. データ前提の確認と含意

入手データは **MSCI ACWI 各ファクターL/Sのトータルリターン指数(日次)** である。この前提が分析設計に与える含意を最初に整理する。

|前提|含意|
|---|---|
|**トータルリターン指数**|配当再投資込み。L/Sなのでロング配当−ショート配当のネット。リターン源泉分解(配当/EPS/マルチプル)は依然できないが、パフォーマンス特性の比較には十分|
|**日次データ**|統計的検出力が高い。ただし日次は自己相関・ボラティリティクラスタリング・ノンシンクロナス取引の影響が強く、年率化やシャープ比算出で補正が必要|
|**L/S構成**|市場ベータが概ね中立化されている前提。ただし完全な中立ではなく残存ベータがありうる点に留意|

日次トータルリターン指数からの基本変換は以下。

$$ r_t = \ln\frac{TR_t}{TR_{t-1}} \quad(\text{対数日次リターン}) $$

対数リターンは時間方向に加法的で、期間集計(年率化、レジーム別累積)がクリーンになるため本分析で採用する。ただしシャープレシオやドローダウンの「投資家が実際に経験する値」を出す場面では単純リターン $TR_t/TR_{t-1}-1$ も併用する。

## 1. 分析の目的と仮説の位置づけ

提案Bは、提案A(回帰によるリターン源泉のプロキシ分解)とは異なり、**クオリティ・ファクターのパフォーマンス特性がレジーム間でどう変質したかを記述・検定する**ことが目的である。

仮説「2023年以降のクオリティ劣後」を、まず**そもそも統計的に有意な劣後なのか**を確認し、劣後しているとすれば**どの特性(リターン水準/ボラティリティ/テールリスク/他ファクターとの相関構造)が変化したか**を多面的に分解する。これは提案A・Cの前段に位置する記述的基盤であり、ここで劣後の存在と性質を確定させてから因果的解釈(A, C)へ進む。

## 2. レジーム定義

### 2.1 外生的分割(ベースライン)

ユーザー仮説に直接対応する分割。

|レジーム|期間|マクロ環境|
|---|---|---|
|QE期|2010-01-01 〜 2021-12-31|超低金利・量的緩和・流動性潤沢|
|移行期(任意)|2022-01-01 〜 2022-12-31|利上げ開始・インフレ加速|
|利上げ後|2023-01-01 〜 現在|高金利定着・QT|

2022年を移行期として分離するか利上げ後に含めるかで結果が変わりうるため、両方で頑健性を確認する。

### 2.2 内生的分割(頑健性確認)

2023年という分割点の恣意性を排除するため、構造変化点をデータから推定する。

- **Bai-Perron 多重構造変化点検定**: 平均リターンの複数のブレークポイントを内生的に特定。推定された変化点が2022-2023近辺に来れば外生的分割を裏づける。
- **CUSUM検定**: 累積残差の逸脱で構造安定性を検証。
- **マルコフ・レジームスイッチング(MS)モデル**: 高ボラ/低ボラ、強気/弱気の潜在レジームを確率的に推定。各時点のレジーム所属確率を出し、暦ベース分割と整合するか確認。

内生的分割が外生的分割と一致すれば仮説の頑健性が高まる。乖離すれば「2023年区切り」自体を再考する。

## 3. レジーム別に算出する指標群

各レジーム×各ファクターで以下を算出する。クオリティを主対象とし、他ファクターは比較基準。

### 3.1 リターン・リスク基本統計

|指標|定義|日次データでの注意|
|---|---|---|
|年率リターン|$\bar{r}_{daily} \times 252$(対数)or 幾何平均年率化|算術/幾何の区別を明示|
|年率ボラティリティ|$\sigma_{daily} \times \sqrt{252}$|自己相関があると過小評価。後述補正|
|シャープレシオ|$(\bar{r} - r_f)/\sigma$ 年率|L/Sは資金中立なので $r_f \approx 0$ で扱うのが一般的|
|ソルティノレシオ|下方偏差のみで除す|テール非対称性を捉える|
|最大ドローダウン|$\max_t(\text{peak}_t - TR_t)/\text{peak}_t$|レジーム内で算出|
|カルマーレシオ|年率リターン / 最大DD|回復力の指標|
|ヒット率|正リターン日の割合|日次では情報量が薄いので月次でも算出|

### 3.2 高次モーメント・テールリスク

レジーム変化はしばしば平均でなくテールに現れる。クオリティは「下方保険」としての性格を持つため、テール特性の変質は運用上重要。

|指標|意味|
|---|---|
|歪度(Skewness)|リターン分布の非対称性。クオリティの保険機能が効いていれば正の歪度|
|尖度(Kurtosis)|テールの厚み。レジーム変化で尖度が上昇していればテールリスク増大|
|VaR / CVaR(95%, 99%)|損失分布の分位点・期待ショートフォール|
|下方/上方キャプチャー|市場下落時・上昇時のクオリティの追随度。クオリティの本質的価値はダウンサイドキャプチャーの低さにある|

### 3.3 自己相関補正シャープレシオ(日次特有の論点)

日次リターンに正の自己相関があると $\sigma\times\sqrt{252}$ がボラを過小評価しシャープを過大評価する。Lo(2002)の補正を適用する。

$$ SR_{annual} = \frac{\bar{r}\times 252}{\sigma \times \sqrt{252}} \times \frac{1}{\sqrt{1 + 2\sum_{k=1}^{q}\left(1-\frac{k}{q+1}\right)\rho_k}} $$

$\rho_k$ はラグ $k$ の自己相関。L/Sファクターは流動性ラグで正の自己相関を持ちやすいため必須。

### 3.4 多重検定調整(Deflated Sharpe Ratio)

レジームを複数試行し、複数ファクターを比較する過程で見かけ上有意なシャープが出る。López de Prado の DSR で補正する。

$$ DSR = \Phi!\left(\frac{(SR - SR_0)\sqrt{T-1}}{\sqrt{1 - \gamma_3 SR + \frac{\gamma_4-1}{4}SR^2}}\right) $$

ここで $SR_0$ は試行回数 $N$ と推定シャープの分散から定まる期待最大シャープ、$\gamma_3,\gamma_4$ は歪度・尖度。DSRが0.95を下回るシャープは偶然と区別できない。

---

## 4. レジーム間比較の統計的検定

指標を算出するだけでなく、**レジーム間の差が統計的に有意か**を検定する。

|検定対象|手法|帰無仮説|
|---|---|---|
|平均リターン差|Welch t検定 / ブートストラップ平均差検定|両レジームの平均リターンが等しい|
|ボラティリティ差|Levene検定 / F検定|分散が等しい|
|シャープレシオ差|Ledoit-Wolf (2008) シャープ差検定(HAC込み)|両レジームのSRが等しい|
|分布全体|Kolmogorov-Smirnov検定|同一分布|
|相関構造変化|Jennrich検定|相関行列が等しい|

特に **Ledoit-Wolf シャープ差検定** は、シャープレシオの差の有意性を自己相関・非正規性に頑健な形で検定でき、本分析の中核となる。

## 5. ファクター間相関構造のレジーム変化

クオリティ単体だけでなく、**クオリティと他ファクターの相関がレジーム間でどう変わったか**を分析する。これは提案Aの $\beta_{Val}$ 変化を相関の観点から補完する。

- 各レジームでファクター間相関行列を算出し、差分行列を可視化(ヒートマップ)。
- 特に **Quality–Value 相関** の変化に注目。QE期から利上げ後にかけてこの相関がより負方向へ動いていれば、クオリティ劣後がバリュー復活と表裏一体(=マルチプル・ローテーション)であることの傍証。
- ローリング相関(60〜120日窓)でクオリティ–バリュー相関の時系列推移を描き、2022-2023の遷移を観察。

## 6. Python実装

```python
import pandas as pd
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# =========================================================
# 0. データ読み込み（トータルリターン指数・日次）
# columns: ['Quality','Value','Size','Momentum','LowVol','Growth'] 等
# =========================================================
tr = pd.read_csv("acwi_factor_ls_totalreturn.csv", index_col=0, parse_dates=True)
tr = tr.sort_index()

# 対数日次リターン（期間集計用）と単純リターン（投資家経験値用）
log_ret = np.log(tr / tr.shift(1)).dropna()
sim_ret = (tr / tr.shift(1) - 1).dropna()

# =========================================================
# 1. レジーム定義
# =========================================================
regimes = {
    "QE (2010-2021)":     ("2010-01-01", "2021-12-31"),
    "Transition (2022)":  ("2022-01-01", "2022-12-31"),
    "Hike (2023-)":       ("2023-01-01", None),
}

def slice_regime(df, start, end):
    return df.loc[start:end] if end else df.loc[start:]

# =========================================================
# 2. パフォーマンス指標算出
# =========================================================
TRADING_DAYS = 252

def lo_adjusted_sharpe(r, q=5):
    """Lo(2002) 自己相関補正シャープ（年率）"""
    mu, sd = r.mean(), r.std(ddof=1)
    sr_d = mu / sd
    rhos = [r.autocorr(lag=k) for k in range(1, q + 1)]
    factor = 1 + 2 * sum((1 - k/(q+1)) * rhos[k-1] for k in range(1, q+1))
    return sr_d * np.sqrt(TRADING_DAYS) / np.sqrt(factor)

def max_drawdown(cum):
    peak = cum.cummax()
    dd = (cum - peak) / peak
    return dd.min()

def cvar(r, alpha=0.95):
    var = np.quantile(r, 1 - alpha)
    return r[r <= var].mean()

def perf_stats(r_log, r_sim):
    ann_ret = r_log.mean() * TRADING_DAYS                  # 対数年率
    ann_vol = r_sim.std(ddof=1) * np.sqrt(TRADING_DAYS)    # 単純年率ボラ
    sharpe_naive = ann_ret / ann_vol
    sharpe_lo = lo_adjusted_sharpe(r_sim)
    cum = (1 + r_sim).cumprod()
    downside = r_sim[r_sim < 0].std(ddof=1) * np.sqrt(TRADING_DAYS)
    return pd.Series({
        "AnnReturn":  ann_ret,
        "AnnVol":     ann_vol,
        "Sharpe":     sharpe_naive,
        "Sharpe_Lo":  sharpe_lo,
        "Sortino":    ann_ret / downside,
        "MaxDD":      max_drawdown(cum),
        "Calmar":     ann_ret / abs(max_drawdown(cum)),
        "Skew":       stats.skew(r_sim),
        "Kurtosis":   stats.kurtosis(r_sim),  # 超過尖度
        "VaR95":      np.quantile(r_sim, 0.05),
        "CVaR95":     cvar(r_sim, 0.95),
        "HitRate":    (r_sim > 0).mean(),
    })

# クオリティについてレジーム別に算出
factor = "Quality"
table = {}
for name, (s, e) in regimes.items():
    rl = slice_regime(log_ret[factor], s, e)
    rs = slice_regime(sim_ret[factor], s, e)
    table[name] = perf_stats(rl, rs)
quality_table = pd.DataFrame(table)
print(quality_table.round(4))

# =========================================================
# 3. シャープレシオのレジーム間差検定（Ledoit-Wolf 風 / ブートストラップ）
# =========================================================
def sharpe_diff_bootstrap(r1, r2, n_boot=10000, seed=42):
    rng = np.random.default_rng(seed)
    def sr(x): return x.mean() / x.std(ddof=1) * np.sqrt(TRADING_DAYS)
    obs = sr(r1) - sr(r2)
    pooled_diffs = []
    r1v, r2v = r1.values, r2.values
    for _ in range(n_boot):
        b1 = rng.choice(r1v, size=len(r1v), replace=True)
        b2 = rng.choice(r2v, size=len(r2v), replace=True)
        pooled_diffs.append(sr(pd.Series(b1)) - sr(pd.Series(b2)))
    pooled_diffs = np.array(pooled_diffs)
    ci = np.quantile(pooled_diffs, [0.025, 0.975])
    pval = 2 * min((pooled_diffs > 0).mean(), (pooled_diffs < 0).mean())
    return {"SR_diff": obs, "CI95": ci, "p_value": pval}

qe   = slice_regime(sim_ret[factor], *regimes["QE (2010-2021)"])
hike = slice_regime(sim_ret[factor], *regimes["Hike (2023-)"])
print(sharpe_diff_bootstrap(qe, hike))

# =========================================================
# 4. 平均リターン差（Welch t）と分布差（KS）
# =========================================================
print("Welch t:", stats.ttest_ind(qe, hike, equal_var=False))
print("KS test:", stats.ks_2samp(qe, hike))

# =========================================================
# 5. 内生的構造変化点（Bai-Perron 簡易版: ruptures）
# =========================================================
# pip install ruptures
import ruptures as rpt
series = log_ret[factor].values
algo = rpt.Pelt(model="rbf").fit(series)
bkps = algo.predict(pen=10)
bkp_dates = [log_ret.index[min(b-1, len(log_ret)-1)] for b in bkps]
print("Detected breakpoints:", bkp_dates)

# =========================================================
# 6. ファクター間相関のレジーム変化
# =========================================================
def corr_in_regime(df, s, e):
    return slice_regime(df, s, e).corr()

corr_qe   = corr_in_regime(sim_ret, *regimes["QE (2010-2021)"])
corr_hike = corr_in_regime(sim_ret, *regimes["Hike (2023-)"])
corr_diff = corr_hike - corr_qe
print("Quality-Value corr  QE:",   corr_qe.loc["Quality","Value"].round(3))
print("Quality-Value corr  Hike:", corr_hike.loc["Quality","Value"].round(3))

# ローリング相関
roll_corr = sim_ret["Quality"].rolling(120).corr(sim_ret["Value"])

fig, ax = plt.subplots(2, 1, figsize=(11, 8))
# 累積リターン（レジーム背景付き）
cum_all = (1 + sim_ret[factor]).cumprod()
cum_all.plot(ax=ax[0], title=f"{factor} L/S Cumulative TR")
ax[0].axvspan(pd.Timestamp("2023-01-01"), cum_all.index[-1], alpha=0.1, color="red")
# ローリング相関
roll_corr.plot(ax=ax[1], title="Rolling 120D Corr: Quality vs Value")
ax[1].axhline(0, color="grey", ls="--", lw=0.8)
ax[1].axvline(pd.Timestamp("2023-01-01"), color="red", ls=":", lw=1)
plt.tight_layout()
```

## 7. 結果の解釈フレームと運用示唆

提案Bは記述的分析であり、単独で因果結論は出さない。ただし以下のパターンで仮説の方向性を絞り込める。

|観察パターン|解釈|次の検証(A/C)|
|---|---|---|
|年率リターンは低下したが**ボラ・ドローダウンは悪化せず、ダウンサイドキャプチャーも維持**|クオリティの保険機能は健在。劣後は「上昇相場に乗れない」型でデレーティング由来の可能性|提案AでβVal拡大を確認|
|**Quality-Value相関が利上げ後に大きく負方向へ**|クオリティ劣後とバリュー復活が表裏一体=マルチプル・ローテーション|提案A・Cで裏づけ|
|**シャープ差がDSR調整後も有意に劣化、かつテール特性も悪化**|単なるローテーション超の構造変質の疑い|提案Aでα劣化を確認、EPSスプレッド要検証|
|Bai-Perron変化点が2022-2023に**一致しない**(例: 2020や2018)|「2023区切り」の仮説前提が脆弱|レジーム定義を再設計|
|シャープ差がDSR調整後**有意でない**|そもそも「劣後」が統計的に確立されていない|仮説自体を棚上げ、データ期間延長|

### 本分析の限界

- トータルリターン指数のL/Sからは**リターン源泉(配当/EPS/マルチプル)を分離できない**。提案Bはあくまでパフォーマンス特性の変質を記述するに留まり、「デレーティング主導」の直接証明はできない。源泉分解の近似は提案A、因果経路は提案Cに委ねる。
- レジーム分割は暦ベースで外生的。内生的検定(Bai-Perron, MS)で補完するが、サンプルが短い利上げ後期間(2023-現在)は推定の不確実性が大きい。検出力不足を明示し、過度な確信を避ける。

## 実行手順のまとめ

1. 日次トータルリターン指数を対数/単純リターンに変換。
2. 外生的レジーム分割でクオリティの全指標を算出(§3)、Lo補正・DSR適用。
3. レジーム間差をブートストラップ/Ledoit-Wolfで検定(§4)。
4. Bai-Perron/MSで内生的分割を推定し外生分割と照合(§2.2)。
5. ファクター間相関のレジーム変化、特にQuality-Valueを分析(§5)。
6. 解釈フレーム(§7)で仮説の方向性を判定し、提案A・Cへ接続。

レジーム定義を金利サイクルの3区分だけに固定するのは、分析目的に照らすと不十分である。理由と代替案を整理する。

## なぜ3区分では不十分か

第一に、**「クオリティ劣後はデレーティング主導」という仮説が金利を主因と想定している以上、金利サイクルだけでレジームを切ると説明変数と分割基準が交絡する**。金利でレジームを定義し、そのレジーム間でクオリティのパフォーマンス差を見て「金利が効いている」と結論づけるのは循環論法に近い。レジーム定義は検証したい因果経路から独立した軸を含むべきである。

第二に、**3区分は単一の暦的軸に過ぎず、クオリティ・ファクターのリターンを駆動する他の状態変数を無視している**。クオリティの挙動はボラティリティ環境、信用サイクル、グロース/バリュー・ローテーション、景気局面によっても大きく変わる。QE期内部にもCOVIDショック(2020Q1-Q2)という極端な局面が含まれており、これを「QE期」として一括りにすると平均が歪む。

第三に、**2023年という分割点が外生的に与えられている**。前回提示したBai-Perron等の内生的検定で、データが実際にどこで構造変化しているかを確認しないまま暦区分を信じるのは、ユーザーの原則(客観性・批判的思考)に反する。

## 推奨するレジーム軸の多層化

単一軸でなく、複数の独立した軸でレジームを定義し、それぞれでクオリティのパフォーマンスを分解することを推奨する。

|軸|レジーム例|識別変数(FRED等で取得可)|仮説との関係|
|---|---|---|---|
|**金利水準・方向**|低位安定 / 利上げ / 利下げ|DGS10, FEDFUNDS の水準と変化|デレーティング経路の直接検証|
|**金利の質**(名目vs実質)|実質金利上昇局面 / インフレ主導局面|DFII10(実質金利), 期待インフレ(T10YIE)|デレーティングは実質金利感応。名目と分離すべき|
|**ボラティリティ**|低ボラ / 高ボラ(リスクオフ)|VIX水準(例: 20で閾値)|クオリティの保険機能はリスクオフで発現|
|**イールドカーブ**|順イールド / 逆イールド / スティープ化|T10Y2Y|景気後退期待。クオリティは後退局面で選好|
|**景気局面**|拡大 / 後退|NBER景気循環, ISM, 失業率|ファンダメンタルズ要因の切り分け|
|**クレジット環境**|タイト / ワイド|BAML HY OAS, クレジットスプレッド|低クオリティのショート脚が反応|

## 具体的な改善提案

**1. 内生的レジームを主、暦区分を従とする**

金利サイクル3区分は「解釈の補助線」として残しつつ、主たるレジーム定義は以下のいずれかでデータ駆動に切り替える。

- **マルコフ・レジームスイッチング(MS)モデル**: クオリティL/Sリターン(または市場リターン)に2〜3状態のMSモデルを当てはめ、各時点のレジーム所属確率を推定する。高ボラ/低ボラ、強気/弱気が内生的に分離され、暦区分と照合できる。
- **Bai-Perron多重構造変化点**: 平均リターンのブレークポイントを推定。検出点が2022-2023に来るか、それとも別の日付(2020, 2018等)に来るかで暦区分の妥当性を判定する。

**2. 二次元クロス分類**

金利軸とボラ軸など2軸でクロス表を作り、各セルでクオリティのパフォーマンスを算出する。例えば「利上げ×高ボラ」と「利上げ×低ボラ」を分けると、クオリティ劣後が金利由来かリスク選好由来かを部分的に切り分けられる。

```
                低ボラ        高ボラ
低金利・安定   セルA          セルB
利上げ局面     セルC          セルD
利下げ局面     セルE          セルF
```

各セルのサンプル数が確保できる範囲で分割する(利上げ後期間が短いためセル数を増やしすぎると検出力が枯渇する点に注意)。

**3. 状態変数への連続的回帰(レジーム離散化の代替)**

そもそもレジームを離散化せず、クオリティL/Sリターンを実質金利変化・VIX変化・カーブ変化に連続回帰する方が情報損失が少ない。これは提案Cの金利感応度回帰そのものであり、提案Bの離散レジーム分析と相互補完する。離散化は可視化・直感的解釈に優れるが、閾値設定の恣意性を伴うため、連続回帰と併用して結論の頑健性を確認すべきである。

## 結論

金利サイクル3区分は出発点として有効だが、それ単独では(1)検証対象と分割基準の交絡、(2)他の状態変数の無視、(3)分割点の恣意性、という3つの問題を抱える。実務上は、金利3区分を解釈の基準線として残しつつ、①内生的レジーム検定(MS, Bai-Perron)で暦区分を検証し、②ボラティリティ・実質金利・カーブなど独立軸を加えた多層レジーム、または③連続的な状態変数回帰を併用する設計を推奨する。

利上げ後期間が短くサンプル数が限られるため、レジームを細分化しすぎると各レジームの推定が不安定化する。軸を増やす場合は1軸あたり2〜3レジームに留め、各レジームの観測日数とDSR調整後の有意性を必ず確認することが前提となる。

どの軸を採用するか方針が固まれば、FREDから識別変数を取得してレジームラベルを生成し、レジーム別サマリーを出力するコードに落とし込む。



## 提案BとCの本質的な違い

| |提案B(レジーム別パフォーマンス分解)|提案C(状態変数への感応度回帰)|
|---|---|---|
|問いの形|「レジームごとにクオリティの特性はどう違うか」|「クオリティリターンは状態変数にどう感応するか」|
|レジームの扱い|レジームを**離散的に分割**して各区間を記述|レジームを離散化せず**連続変数**として扱う|
|出力|レジーム別のリターン/ボラ/シャープ/テール特性|金利・VIX等への回帰係数(感応度)|
|強み|各局面の特性を直感的・網羅的に記述|閾値の恣意性がなく情報損失が小さい|
|弱み|分割点・閾値が恣意的|「局面ごとの質的な違い」が見えにくい|

前回「連続回帰の方が情報損失が少ない」と述べたのは事実だが、それは**Cがレジームスイッチングを精緻にやる手法だという意味ではない**。Cはそもそもレジームを離散化しないアプローチであり、「レジームスイッチングの精緻版」ではなく「レジームを離散化しない代替」である。

## レジームスイッチングを精緻にやりたいなら、BでもCでもなく第三の道

「レジームスイッチングを精緻に分析する」ことが目的なら、適切なのは提案Bの内部で言及した**マルコフ・レジームスイッチング(MS)モデル**であり、これはBともCとも区別される独立した手法系統である。

MSモデルは、レジームを外生的な暦区分や閾値で与えるのではなく、**潜在状態として確率的に推定する**。

$$ r_t = \mu_{S_t} + \sigma_{S_t},\epsilon_t, \quad S_t \in {1,\dots,K} $$

状態 $S_t$ は観測されず、状態間の遷移確率行列 $P_{ij} = \Pr(S_t=j \mid S_{t-1}=i)$ と各状態のパラメータ $(\mu_k, \sigma_k)$ を最尤推定する。各時点のレジーム所属確率(スムージング確率)が出力されるため、「いつ・どの確率でレジームが切り替わったか」をデータから内生的に特定できる。

これが「レジームスイッチングの精緻化」の本来の答えである。提案Bの離散分割が恣意的だという問題への正攻法はCへの移行ではなく、MSモデルによる**内生的レジーム推定**である。

## 三者の正しい位置づけ

```
レジームをどう扱うか
├─ 外生的に暦・閾値で分割     → 提案B(記述的、直感的、恣意性あり)
├─ 内生的に潜在状態として推定 → MSモデル(レジームスイッチング精緻化の本道)
└─ 離散化せず連続変数で回帰   → 提案C(情報損失最小、感応度の定量化)
```

これらは競合ではなく階層的に補完する。実務的な推奨フローは以下になる。

1. **MSモデルで内生的レジームを推定** → データが実際にどこで何状態に切り替わるかを確定。暦区分(2023年)が裏づくか検証。
2. **提案Bで各レジームの特性を記述** → MSが特定したレジーム(または検証された暦区分)を使い、クオリティのリターン/テール特性を分解。MSが出した確率的レジームを分割ラベルに使えばBの恣意性が解消される。
3. **提案Cで連続的感応度を定量化** → レジーム離散化と独立に、実質金利・VIX等への感応度を回帰で測定。Bの離散的結論とクロスチェック。

## 結論

「レジームスイッチングを精緻に分析するならCを行うべき」は誤り。Cはレジームを離散化しない別アプローチであって、レジームスイッチングの精緻版ではない。

- レジームスイッチング自体を精緻にやりたい → **MSモデル**(BでもCでもない第三の手法)
- 各レジームの特性を記述したい → **提案B**(MSの出力をレジームラベルに使えば精度向上)
- レジーム離散化の恣意性を回避し感応度を測りたい → **提案C**

仮説検証の観点では、MSで内生的レジームを確定し、その上でBの記述とCの感応度回帰を併用するのが最も頑健である。三者は代替ではなく補完関係にある。

MSモデルの実装(statsmodelsの`MarkovRegression`/`MarkovAutoregression`、状態数の選択基準、レジーム所属確率の暦区分との照合まで)に進むなら、コードと状態数決定のフレームを具体的に提示する。
