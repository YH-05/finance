# [K9] KB拡張: スケールメリットと増収効果の識別基準

> **区分**: KB 評価判定
> **優先度**: 高
> **トリガー銘柄**: CPRT
> **トリガーClaim**: #6 オンラインプラットフォームのスケールメリット

## 論点

### AI評価（CA 50%）

根拠:
- 「SGA率は6年前の10%半ばから9%へ一貫して低下」
- 「営業利益率35%と非常に高い」
- オンラインプラットフォームのスケールメリットを認定

### Yの反論（Feedback_CPRT.md #6）

> 「主張にある**OPM改善は増収にともなう効果であり、スケールメリットに起因するものとは考えない**」
>
> 「あくまで2社寡占に近い状況（#4）に規定された中での『スケール』との考えであり CA評価は＃６＜＃４」

Y評価: CA 30% / CAGR 30%（AIの50%から -20pt）

## 問題の本質

### 「スケールメリット」の用語濫用

財務指標の改善は複数の要因で起きうる:

| 現象 | 背後のメカニズム | スケールメリット判定 |
|------|----------------|------------------|
| SGA率低下 | 固定費の絶対額が増収率未満で推移 | ✅ 本物のスケール |
| SGA率低下 | 売上（分母）増で比率希薄化、固定費も比例増 | ❌ 単なる増収効果 |
| SGA率低下 | 一時的コスト削減（人員削減等） | ❌ スケールではない |
| OPM改善 | Fixed cost leverage | ✅ 本物のスケール |
| OPM改善 | 価格転嫁 / ミックス改善 | ❌ スケールではない |

**現行AIの問題**: 「SGA率改善」を見ると即「スケールメリット」と判定する傾向。

### 区別のための分析

**本物のスケールメリットの条件**:

```
売上成長率 > 固定費成長率
かつ
固定費の絶対額が一定閾値以下で推移
```

**増収効果に過ぎない条件**:

```
SGA絶対額 ≒ 売上成長率（比例増加）
または
SGA率は低下しているが COGS率は変化なし（固定費でなく売上総利益ベースで改善）
```

### KB3銘柄との比較

| 銘柄 | Claim | スケール判定 |
|------|-------|------------|
| COST #1 会員制 | 固定費（店舗・IT）を会員数で割る→会員増で逓減 | ✅ 本物 |
| ORLY #2 規模密度 | DC網の固定費を店舗数で割る | ✅ 本物 |
| CPRT #6 | SGA率低下だが、IAA対比のコスト差は不明 | **判定保留**（Yは ❌ と判定） |

## KB改訂案

### Proposal A: スケールメリット判定の必須チェックリスト

claims.json に「スケールメリット」Claim が立てられた場合、以下の証拠提出を必須化:

1. **固定費絶対額の時系列推移**（絶対額が横ばい or 増収率未満）
2. **競合との比較**（同規模競合より低いコスト率 / 大規模化に伴う差の拡大）
3. **単位あたりコスト**（Unit当たりSGA, 取引あたりSGAなど）の低下
4. **切り分け可能な会計分析**（固定費 vs 変動費の分解）

少なくとも2項目で裏付けがない場合は、confidence 上限を 50% に制限。

### Proposal B: 階層判定との組み合わせ

Claim #6 スケールメリットが Claim #4 複占（市場構造）の下位概念である場合:

- スケールの源泉が**複占構造に依存**（新規参入がないから固定費が希薄化できる）
- → スケールメリット単独の評価は不可。複占構造 Claim に統合するか、従属関係を明示。

CPRT の場合:
- 複占がなければスケールメリットは成立しない可能性 → #6 は #4 の下位（K7 で定式化）
- 独立の優位性として加点するのは二重カウント

### Proposal C: 増収効果との識別キーフレーズ

主張原文で以下のキーフレーズが使われていたら「要注意」として extractor にフラグ:

| キーフレーズ | 疑うべきこと |
|------------|-----------|
| 「SGA率の低下」 | 絶対額と売上成長率の比較が必要 |
| 「営業レバレッジ」 | 固定費と変動費の分解が必要 |
| 「規模の優位」 | 競合比較が必要 |
| 「マージン拡大」 | ミックス改善や価格転嫁でない証拠が必要 |

### Proposal D: CPRT #6 再評価

Proposal A-C を適用した場合の CPRT #6 再評価:

- 固定費絶対額の時系列: 未検証（要追加調査）
- 競合（IAA）との比較: 定量データなし
- 単位あたりコスト: 未検証
- 会計分解: 未実施

→ 証拠2項目未達成 → **confidence 上限 50%**（実質 30-50% レンジ）
→ Y評価 30% と整合

| 項目 | AI評価 | Y評価 | 乖離原因 | 提案後の整合性 |
