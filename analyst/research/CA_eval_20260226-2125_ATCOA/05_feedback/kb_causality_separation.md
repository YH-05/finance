# [K5] KB拡張: 複合因果チェーンの個別検証原則

> **区分**: KB 評価手法
> **優先度**: 中
> **トリガーClaim**: #4 変動費型コスト構造（ATCOA）

## 論点

### AI側のClaim #4 CAGR接続記述

> 「変動費型構造→景気後退時のMargin Floor維持→サイクルを通じた安定的EPS CAGR。**アフターサービス比率向上→Recurring収益→OPレバレッジ1%への寄与**」

### Yの分離指摘

> 「CAGR評価のうち、**『変動費型構造→景気後退時のMargin Floor維持→サイクルを通じた安定的EPS CAGR』　には同意**」

> 「CAGR評価のうち、**『アフターサービス比率向上→Recurring収益→OPレバレッジ1%への寄与。』では、変動費型費用構造とアフターサービス比率向上の関連はないため同意せず**」

## 問題の本質

### 複合因果チェーンの罠

AI側が1つのClaimで複数の因果チェーンを混在させた例:

```
Claim #4「変動費型コスト構造」のCAGR寄与:
├─ Chain A: 変動費型 → Margin Floor → EPS安定   [Yも同意]
└─ Chain B: アフターサービス比率↑ → Recurring → OPレバ   [Yは無関係と判定]
```

→ Chain B は**独立した優位性**（Claim #1 スイッチングコストのサブ要素）であり、Claim #4「変動費型」とは因果関係がない

### 混在の発生源

| 発生パターン | 例 |
|------------|-----|
| 数値目標に複数優位性を総動員 | CAGR +1% を説明するために関連薄い要素を追加 |
| 異なる会計概念の混同 | Cost構造 と Revenue構造を混ぜる |
| アナリスト原文の曖昧さを継承 | ANが総論的に記述 → AIがそのまま採用 |

## KB基準の改訂案

### 原則: **1 Claim = 1 因果チェーン**

各Claimは**単一の因果チェーン**のみを含むべき。複数の因果チェーンがある場合は**Claim分割**を行う。

### Claim分割ルール

```
BEFORE (混在):
Claim #4「変動費型コスト構造」
  CAGR寄与: [変動費→Margin Floor] + [アフター比率→Recurring]

AFTER (分割):
Claim #4A「変動費型コスト構造」
  CAGR寄与: [変動費 → Margin Floor → EPS安定]

Claim #4B「アフターサービス比率向上」  ※Claim#1の派生として統合 or 独立化
  CAGR寄与: [アフター比率 → Recurring収益 → OPレバ]
```

### 因果チェーン検証フレームワーク

各Claimに対して:

```markdown
### CAGR接続の因果チェーン

1. 因果の起点: [優位性の要素A]
2. 中間メカニズム: [メカニズムB]
3. 中間結果: [結果C]
4. 最終数値寄与: [CAGR前提X]

### 各リンクの独立性検証
- [ ] A → B は A 固有の効果か（他優位性でも代替可能ではないか）
- [ ] B → C は A の介在なしに成立しないか
- [ ] C → X は他ドライバーと混ざっていないか
```

### Claim#4 再構成例

**修正前**:
- Claim#4: 変動費型 → Margin Floor + アフター比率 → OPレバ

**修正後**:
- **Claim#4**: 変動費型 → Margin Floor維持 → サイクル安定EPS（CA 30%/CAGR 30%）
- **Claim#4補足**: OPレバ1%のうちアフター比率寄与は Claim#1派生として再配分
