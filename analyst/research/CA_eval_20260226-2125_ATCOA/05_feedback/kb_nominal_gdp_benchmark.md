# [K4] KB拡張: 名目GDP基準による成長率優位性判定

> **区分**: KB 評価基準新設
> **優先度**: 中
> **トリガーClaim**: #1 スイッチングコスト、#7 プライシング（ATCOA）

## 論点

### Yの基準提示

> 「コンプレッサー事業では電力代削減を通して顧客ＴＣＯに寄与するため顧客粘着度への確度は高い。一方でエンドも分散されている中での**+4％成長は名目GDP（実質2-3％、インフレ1-2％）成長に即したもの**であり、**より高いスイッチングコストに裏付けされた成長とはいいがたい**」

> 「広範なエンド顧客を有するコンプレッサー事業でのOG成長+4％は、**名目GDP並みであり達成バーは低く、達成確度は高いが、『競争優位性としてのプライシング効果』に支えられた売り上げとはいいがたく納得度は低い**」

## 問題の本質

### 成長率評価の二段階構造

Yの評価ロジックは以下の二段階:

```
STAGE 1: 達成確度（CAGR前提の実現可能性）
  ├─ 名目GDP並み: 高確度（バーが低い）
  └─ 名目GDP超過: 低確度（バーが高い）

STAGE 2: 優位性裏付け度（その成長が優位性に支えられているか）
  ├─ 名目GDP並み: 裏付け弱い（経済成長の自然享受）
  └─ 名目GDP超過: 裏付け強い（市場シェア獲得・価格力の結果）
```

→ **達成確度が高いことと、優位性に裏付けられていることは独立**

### ATCOA セグメント別適用

| セグメント | OG成長 | 名目GDP対比 | Stage1確度 | Stage2優位性裏付け |
|----------|--------|-----------|-----------|-----------------|
| CT | +4% | ≈ 名目GDP | 高 | **弱** |
| VT | +8% | > 名目GDP (+5pt) | 中 | **強** |

→ 「CAGR確度は バキューム > コンプレッサー」の根拠

## KB基準の新設案

### 基準名: **名目GDP超過率による優位性寄与判定**

```
優位性寄与率 = (OG成長率 - 名目GDP成長率) / OG成長率
```

| 名目GDP超過 | 優位性寄与率 | Stage2評価 |
|-----------|-----------|-----------|
| > +5pt | > 60% | 優位性が主要成長ドライバー |
| +2〜+5pt | 30-60% | 優位性が一部寄与 |
| -2〜+2pt | < 30% | 経済成長の自然享受が主体 |
| < -2pt | ネガティブ | 市場シェア喪失 |

### 地域別適用

名目GDPは地域×期間で異なるため:

| 地域 | 名目GDP目安（2020s） |
|------|------------------|
| 米国 | 4-5% (実質2-3% + インフレ2%) |
| 欧州 | 3-4% |
| 先進国平均 | 4% |
| グローバル | 5-6% |
| 新興国 | 6-8% |

→ 企業の地域売上構成に応じた加重平均を使用

### ATCOA 再評価

**Claim #1 CAGR接続の検証**:
- CT OG +4% → 先進国中心の売上構成 → 名目GDP 4%相当 → **超過率 ≈ 0**
- Stage2優位性寄与: **弱** → #1スイッチングコストの「成長への寄与」は限定的
- → Y評価 CAGR 50% の根拠

**Claim #7 プライシング**:
- CT LfL 1-2% → インフレ並み → 価格力の優位性として**中立以下**
- VT セミコン向け フラット → 価格力**なし**
- → Y評価 CAGR 30% の根拠

|------|-------|--------|-----------|-----------|
| COST | 会員成長 | +6% (米) | +2pt | 30-60% |
| CHD | OG | +3% | -1pt | < 30% |

→ KB3内でも優位性寄与度にばらつき。名目GDP基準は**バックテスト可能**な指標。

## アクション

1. KB v1.1に「名目GDP超過率による優位性寄与判定」基準を追加
2. market-data収集時に企業の地域売上構成を取得
3. CAGR接続評価時に Stage1 / Stage2 を分離して記載
4. KB3全銘柄に対して本基準を遡及適用し整合性検証
