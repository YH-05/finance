# 軸G: 国内機関投資家の IR 評価軸

**作成日**: 2026-05-11
**目的**: 国内機関投資家×シード期 LP 向けに、評価軸・選定基準を把握しピッチ資料の構造に反映
**位置付け**: 応用 — LP訴求設計（ファンドコンセプト「アナリストYの暗黙知 × マルチエージェント」）

---

## エグゼクティブサマリ

国内機関投資家（GPIF・年金・生損保）の運用機関選定は **「定量実績」よりも「定性評価」のウェイトが上昇** している。GPIF は2018年以降、定量評価を点数化せず「定量データを加味した定性評価」に切替え、6評価軸（投資方針/運用プロセス/組織・人材/事務処理/リスク管理/コンプライアンス）の総合審査を行う運用に転換した（出所: GPIF「総合評価方法の見直しについて」経営委員会311回資料）。

シード期ファンドにとって最大の構造的追い風は **アセットオーナー・プリンシプル（AOP）補充原則3-4** である。2024年8月策定の AOP は **「新興運用業者を単に業歴が短いことのみをもって排除しないことが重要」** と明記し、2026年2月時点で142機関が受入表明済。さらに金融庁は **新興運用業者促進プログラム（日本版EMP）** を2024年に開始、JICによるエンゲージメントファンド出資・大手金融グループのEMP取組事例公開・登録要件緩和（資本金5,000万円→1,000万円、ミドルバック外部委託可、2025年5月施行）を実行している。

ただし「業歴排除はしないが、運用責任者の能力・経験・運用プロセスの再現性・リスク管理体制は厳格に審査する」という構造であり、シード期ファンドが訴求すべき軸は **「PoCトラックレコード＋運用プロセスの再現性＋リスク管理体制＋ガバナンス・利益相反管理」** の4点に絞られる。

AI ファンドへの追加的論点として、**説明可能性（XAI）・モデルガバナンス・データ管理・第三者AIベンダーの集中度リスク** が日銀「金融システムレポート」「金融行政方針2025」で警鐘されており、AI 起因のブラックボックス化・過学習・データマイニング過剰利用が定性評価の減点項目となる。逆に **マルチエージェント＋暗黙知形式知化** という構造は「人間アナリストの判断パスを可視化＝XAI を本質的に満たす」設計として LP 訴求の差別化軸になり得る。

LP 訴求の直接活用可能度: **高**（具体的な評価項目に対応するピッチ章立てが特定可能）。

## 1. GPIF の運用機関選定プロセス

### 1.1 公募応募（マネジャー・エントリー制度）の基本要件

GPIF は2018年4月から **マネジャー・エントリー制度** を導入。常時公募。主な応募資格（出所: GPIF「公募説明会資料」2021-04-28、「2. 運用機関公募に対する応募（エントリー）資格」）:

| 要件 | 内容 |
|------|------|
| 投資運用業の登録 | 金商法（昭和23年法律第25号）に基づく投資運用業の登録 |
| 運用資産残高 | グループ全体で年金運用資産1,000億円以上（不足時は機関投資家・大学基金からの受託残高加算可） |
| 応募プロダクト | 原則5年以上の運用実績、運用資産残高300億円以上 |
| 再々委託禁止 | 実質的投資判断の再委託先内部完結 |
| 直近3年違反なし | グループ内で資金運用業務に関し著しく不適当な行為がないこと |

**シード期ファンドにとっての含意**: GPIF の応募資格を直接満たすのは困難（残高1,000億円、実績5年、300億円）。ただし2023-2024年に **新興運用業者の促進** が政府方針となり、後述のEMP経由・ゲートキーパー経由・グループ会社経由のルートが選択肢として明示された。

### 1.2 審査プロセス（3次審査+総合評価）

1. **第1次審査**: 書類審査（応募要件、運用実績、組織体制）
2. **第2次審査**: ヒアリング・面談（プロダクト特性、ファンドマネジャー・ゲートキーパーの運用能力）
3. **第3次審査**: 現地面談（運用体制、運用能力、総合評価点確定）
4. **採用決定**: 適正運用サイズ・リスク・スタイル分散の観点から運用機関構成検討、投資一任契約締結

### 1.3 総合評価の6軸（2018年改訂で点数化廃止→定性評価中心へ）

出所: GPIF「総合評価方法の見直しについて」経営委員会311回資料

| 評価軸 | 主要評価ポイント |
|--------|------------------|
| **投資方針** | 投資哲学の妥当性、市場の効率性への認識、付加価値の源泉 |
| **運用プロセス** | 投資方針との整合性、付加価値追求方法の合理性、運用実績による有効性裏付け、リスク管理 |
| **組織・人材** | 投資方針の組織徹底、意思決定の流れと責任所在、経験を有するマネジャー配置、運用成果と整合的な報酬、ガバナンス・利益相反管理 |
| **事務処理体制** | 売買・決済の効率性・正確性、運用実績報告の迅速性・正確性・透明性 |
| **リスク管理** | 実効性、適切性 |
| **コンプライアンス** | 法令・運用ガイドライン遵守、過去の違反、事故対応、監査体制 |

**重要なポイント**: 2018年改訂で **定量評価の点数化を廃止** し「定量データを加味した定性評価」へ移行。理由は「中長期にわたる超過収益獲得の質を判断するには、運用プロセスや組織・人材の質を多面的に評価することが不可欠」（GPIF 2018）。コンサルタント2社のレーティング・評価情報も活用。

### 1.4 2022-2024年のデータサイエンス活用評価

GPIF は2022年度下半期から **「最新のデータサイエンスに基づく定量評価」** を株式アクティブファンド選定に導入。北米株19ファンド（2022）、先進国株14ファンド・国内株23ファンド（2023）、北米株12ファンド・先進国株（除北米）17ファンド（2024）を選定（出所: 内閣官房「企業年金・GPIFの資産運用の状況について」、GPIF業務概況書）。

**マネジャーの投資戦略・保有銘柄等のデータを分析してマネジャーの銘柄選択能力をより正確に判定** する手法を確立。スタイルリスクは「ベータ・バランサー」と呼ばれるパッシブファンドで調整。

### 1.5 マネジャー・エントリー資格の緩和

GPIF は2023-2024年に **「優秀な運用機関を採用できるよう、マネジャー・エントリー資格として求めていた運用資産の残高要件やファンドの実績年数の要件を撤廃し、新興運用業者を含めて運用機関の採用対象範囲を拡大」** （出所: 内閣官房資料）。これは新興ファンドにとって直接的な追い風。

## 2. スチュワードシップコード（日本版）の含意

### 2.1 改訂履歴と2025年第3次改訂

- 2014年2月: 初版策定
- 2017年5月: 第1次改訂（アセットオーナー役割明確化）
- 2020年3月: 第2次改訂（サステナビリティ・議決権行使助言会社）
- **2025年6月: 第3次改訂**（5年ぶり）

受入機関数: 334機関（2024年6月時点、運用機関215、年金基金等77、その他10）

### 2.2 2025年改訂のポイント

出所: 金融庁「スチュワードシップ・コード（第三次改訂版）の確定について」（2025-06-26）、大和総研レポート、大和アセットレポート

1. **実質株主の透明性向上**（指針4-2）: 「投資先企業からの求めに応じて、自らがどの程度投資先企業の株式を保有しているかについて企業に対して説明すべき」と「注」から「指針」に格上げ
2. **協働エンゲージメント促進**（指針4-6）: 「他の機関投資家と協働して対話を行うこと（協働エンゲージメント）も重要な選択肢である」と表現格上げ（旧コード「有益な場合もあり得る」→新コード「重要な選択肢」）
3. **コードのスリム化**: 3年ごとの定期見直し記載削除

### 2.3 運用機関への含意

- 投資先企業との **建設的な「目的を持った対話」（エンゲージメント）** を通じた企業価値向上が中核責任
- **議決権行使と対話は点と線の関係**（FSA フォローアップ会議）
- **形式的・一律対応ではなく個別企業事情の深い理解** が必要
- 運用機関のスチュワードシップ活動が **運用機関の選定・報酬設定に適切に反映** されているかが論点（金融庁2024事務局説明資料）

**シード期ファンドへの含意**: 「中長期的な企業価値向上に資する個別企業事情の深い理解」を提示することが SS コード適合性のアピールになる。アナリストYの暗黙知形式知化はまさにこの軸に直結。

## 3. 国内年金（厚生年金、企業年金）の運用機関選定

### 3.1 確定給付企業年金（DB）の資産運用ガイドライン

出所: 厚生労働省「確定給付企業年金に係る資産運用関係者の役割及び責任に関するガイドライン」（平成14年通知、平成30年4月改訂）、企業年金連合会「受託者責任ハンドブック」（令和7年7月版）

**DB は厚生労働省ガイドライン管轄、GPIF とは別建て**。100億円以上の基金には資産運用委員会の設置が義務化（2018年改訂）。

### 3.2 運用受託機関の選任基準（定性評価6項目）

| 項目 | 評価ポイント |
|------|---------------|
| **投資方針** | 市場の効率性・非効率性への認識、付加価値追求方法、ESG・SSコード取組方針 |
| **組織・人材** | 意思決定の流れ・責任所在の明確性、専門性・経験を有する人材配置、人材定着度・運用継続性・再現性 |
| **運用プロセス** | 投資方針との整合性、**運用の再現性**、リターン追求方法の合理性・有効性、リスク管理指標の合理性・有効性 |
| **事務処理体制** | 売買・決済の効率性・正確性、報告の迅速性・正確性・透明性 |
| **リスク管理体制** | 実効性、適切性 |
| **コンプライアンス** | 法令・ガイドライン遵守体制、過去の違反、監査状況 |

**注目ポイント**: **「運用の再現性」が独立項目** として明示されている（GPIF 同様）。これは AI ファンドにとって重要な評価軸。

### 3.3 企業年金連合会（PFA）の運用受託機関評価

- 経営理念、経営内容、社会的評価
- 企業年金制度に対する理解と関心
- 運用方針・運用スタイル・手法
- 情報収集システム、投資判断プロセス、運用管理体制
- 法令遵守体制
- 運用担当者の能力・経験
- 年金運用の経験と実績

中長期評価ベース。市場価格大幅変動時・政策アセットミックス見直し時には評価にかかわらず構成変更可。

### 3.4 信託銀行・生保（運営管理機関）の年金運用評価

- **3信託銀行**（三井住友信託、三菱UFJ信託、みずほ信託）と **大手生保**（日本生命、第一生命、明治安田、富国）が中核
- 「年金情報」アクティブ運用定性満足度（2025年集計）上位: 東京海上アセット、野村アセット、アセットマネジメントOne、三菱UFJオルタナティブ、SOMPOアセット
- **総合幹事会社モデル** は資産規模（AuM）報酬連動のため緊張感が薄いと BCG が指摘（金融庁2022年企業年金調査）

### 3.5 アセットオーナー・プリンシプル（AOP）2024年8月策定

出所: 内閣官房「アセットオーナー・プリンシプル」（2024-08-28）

**5原則 + 補充原則**

| 原則 | 内容 |
|------|------|
| 原則1 | 運用目的の明確化（運用目的・運用目標・運用方針の策定） |
| 原則2 | 専門的知見の確保・体制整備（**OCIO等外部委託の検討**） |
| 原則3 | 受益者等の利益観点での運用方法選定、リスク管理 |
| 原則4 | ステークホルダーへの説明責任・見える化 |
| 原則5 | 投資先企業の持続的成長への積極的働きかけ（SSコード受入） |

**最重要 — 補充原則3-4**:
> 「アセットオーナーは、運用委託先の選定に当たっては、過去の運用実績等だけでなく、投資対象の選定の考え方やリスク管理の手法等も含めて総合的に評価すべきである。**その際、知名度や規模のみによる判断をせず、運用責任者の能力や経験（従前の運用会社での経験等を含む）を踏まえ、検討を行うことが望ましい。例えば、新興運用業者を単に業歴が短いことのみをもって排除しないようにすることが重要である**。」

**受入機関数**: 2026年2月時点で142機関（公的年金等14、企業年金54、保険32、学校法人19、その他1）（出所: 内閣官房 2026年3月資料、野村アセット報告書）

## 4. 国内生損保のアクティブ運用評価

### 4.1 日本生命

- **PRI年次評価で5つ星**（ポリシー・ガバナンス・戦略、上場株式アクティブ、債券アクティブ、信頼醸成措置、2024年）
- 環境省「ESGファイナンス・アワード・ジャパン」投資家部門 銅賞（2024）、金賞・環境大臣賞（2023）
- ニッセイ基礎研究所独自のインデックスモデル使用
- 委託先選定: ボトムアップ、ベンチマーク超過、ESG統合
- トランジション・ファイナンスのアセットレベル評価実施

### 4.2 第一生命

出所: 第一生命「2025年度第1四半期運用方針」、「R&I ファンド大賞2024」受賞リリース

- **マーサーをゲートキーパーとして活用**（マーサー・グローバル・インベストメンツ・ヨーロッパ・リミテッドが外国投資信託を設定し、運用判断を WCM／DoubleLine／Janus Henderson 等に委託）
- 国内株式アクティブは **特別勘定第1特約円貨建株式口1型**（TOPIX対比、ボトムアップ）が「R&I ファンド大賞2024 確定給付年金部門 国内株式グロース」2年連続受賞
- 運用方針: 「定量分析の再現性、一貫性を重視しつつ、運用環境の変化に応じて有効性を検証し、適宜見直しを行う」

### 4.3 評価軸の共通項

- 運用責任者の経験・能力
- 投資哲学・スタイルの明示
- ESG／SSコード／PRI 取組
- 集中投資型 vs 分散型のスタイル明示
- 定量分析の **「再現性」「一貫性」**（第一生命運用方針より直接引用）
- ALMとアクティブのバランス（負債特性に応じたアセットアロケーション）

**含意**: 生保はマーサー等の OCIO／ゲートキーパー経由で外部運用機関を活用するチャネルが確立されており、シード期ファンドは **OCIO 経由のアクセス** が現実的なルート。

## 5. AI ファンドへの評価軸

### 5.1 規制・ガバナンスの現状（日本）

- 金融庁「金融行政方針2025」（2025年8月）: AI の利活用と規制のバランス、アセットオーナー・プリンシプル受入推進
- 日本銀行「金融システムレポート」（2024年4月）: **AI／機械学習活用に伴う新たなリスク**（学習データ偏り、ブラックボックス化、プライバシー、アルゴ取引によるボラ増幅、情報セキュリティ）を明示
- 金商法上の AI ファンド特別規制は **存在しない**（投資運用業の登録要件・行為規制の枠内で対応）

### 5.2 説明可能性（XAI）の要求

出所: BIS XAI 専門論文（2023）、Meta-Intelligence「金融業界AIコンプライアンスガイド」、CFA Institute 研究、野村サステナビリティクォータリー2024

- SHAP／LIME 等の XAI 技術には **不精確性・不安定性** という本質的限界
- 規制当局・リスクマネージャー・投資専門家・開発者・顧客で **説明ニーズが異なる**
- 「性能 vs. 説明可能性」のトレードオフは規制当局が許容を検討中
- **多層的な説明能力**（グローバル説明・ローカル説明・技術説明）の構築が推奨される

### 5.3 GPIF の AI 活用調査（2017）

GPIF は2017年に **「AI が資産運用に与える影響について」** 調査（Accenture共同）を実施。委託運用高度化における AI 活用機会として、ファンド評価・リスク管理・レポート作成・情報収集の自動化を整理。**業務効率化と運用高度化の両面**で活用機会を評価。

ポイント: GPIF は AI／機械学習の活用そのものに肯定的だが、**運用受託機関側の AI 活用**は「定量データを加味した定性評価」の素材として扱われる。

### 5.4 AI ファンドへの想定評価項目（クロス検証ベース）

| 評価項目 | 評価ポイント | リスク |
|----------|--------------|--------|
| **モデル説明可能性（XAI）** | 投資判断の主要ドライバーが説明可能か、ローカル・グローバル両説明能力 | SHAP/LIME 単独依存はNG |
| **再現性（Reproducibility）** | 同一データ・モデルでの再実行で同一出力、シミュレーションデータと実運用の接続根拠 | データマイニング過剰利用、過学習 |
| **データガバナンス** | 学習データの偏り、プライバシー、データ集中度リスク | 低金利・低ボラ期データ偏重 |
| **モデルリスク管理** | ストレステスト、フォワードルッキングなリスク分析、VaR等定量指標 | 想定外シナリオでのモデル崩壊 |
| **第三者AIベンダー依存** | ベンダーロックインリスク、データ主権、モデルポータビリティ | 集中度リスク（BIS／FSB懸念事項） |
| **AIコンプライアンス体制** | AI ガバナンス委員会、リスク分類、本番投入審査 | ガバナンスと説明責任の不在 |
| **アルゴリズム取引の市場影響** | ボラティリティ増幅可能性、市場の歪み | 日銀FSR警鐘事項 |

### 5.5 「マルチエージェント × 暗黙知形式知化」の評価軸への適合性

ファンドコンセプト固有の優位性として、以下が想定される:

- **判断パスの可視化** = XAI を構造的に満たす（人間アナリストの判断軸をエージェント化することで、各判断の根拠が個別エージェント単位で追跡可能）
- **再現性** = 同一データで同一判断パスを辿る設計が可能
- **モデルリスク管理** = エージェント単位でのストレステストが可能
- **第三者ベンダー集中度回避** = 自社で判断ロジックを構成可能

**ただし弱点**: 暗黙知の形式知化精度をどう検証するか、ベンチマーク超過の根拠をどう示すか、シード期ゆえのトラックレコード不足は依然として残る。

## 8. シード期ファンドの評価ポイント — トラックレコード代替軸

シード期ファンドが GPIF・年金・生保・OCIO の評価軸を満たすには「実績」以外の代替的評価項目を厚く設計する必要がある。AOP補充原則3-4 と GPIF/DB ガイドラインの定性6軸を踏まえると、以下の優先順位で訴求すべき。

### 8.1 訴求軸の優先順位（高→低）

| 優先度 | 訴求軸 | 評価軸との対応 | 訴求方法 |
|--------|--------|----------------|----------|
| 1 | **運用責任者の能力・経験**（前職での運用実績含む） | AOP 3-4 明示、GPIF 組織・人材 | 経歴書、過去ファンドのパフォーマンス、論文・寄稿、専門家評判 |
| 2 | **投資哲学の明示と運用プロセスの再現性** | GPIF/DB 投資方針・運用プロセス | 暗黙知形式知化の手法、判断パスの可視化、PoCバックテスト結果 |
| 3 | **リスク管理体制** | GPIF/DB リスク管理 | VaR、ストレステスト、ドローダウン管理、フォワードルッキング分析 |
| 4 | **ガバナンス・利益相反管理** | GPIF/DB コンプラ・組織 | 役員構成、社外取締役、利益相反管理規程、監査体制 |
| 5 | **AI／XAI・モデルリスク管理** | 新興評価軸 | XAI 説明インフラ、データガバナンス、モデルカード、定期再学習 |
| 6 | **PoC トラックレコード**（短期間でも） | GPIF 2018年改訂で「シミュレーションデータ接続OK」 | 「スマートベータ型やクオンツ運用で銘柄選定手法がルール化されている条件下では、シミュレーションデータを実績に接続するケースは従来からある」（GPIF経営委員会311回） |
| 7 | **ESG／SSコード／PRI 受入予定** | AOP 原則5、SSコード | 受入表明予定、エンゲージメント方針 |
| 8 | **第三者からの推薦**（マーサー等のコンサル評価、JIC・EMP 認定） | OCIO レーティング | 早期段階での外部評価獲得 |

### 8.2 GPIF 2018年改訂が示すシード期ファンドの裏ルート

GPIF経営委員会311回資料の「定量評価の点数化を行わないことにより、今後は運用実績がないファンドが定性評価のみで採用されるようになるのか」への回答:

> 「原則として運用実績がないファンドが採用されるのは困難である。**ただし、スマートベータ型やクオンツ運用で銘柄選定手法がルール化されているという条件でシミュレーションデータを実績に接続するケースは従来からあり、定性的に根拠が確信できる手法であればシミュレーションデータのみで採用に至る可能性はある**。」

**含意**: AI／マルチエージェントによるルール化された銘柄選定手法であれば、シミュレーションデータ（バックテスト）の質と「定性的根拠の確信度」が決め手になる。これは LP 訴求の最重要ヒント。

### 11.3 1ページレターサイズ（Investment Memo）の章立て

1. **Strategy**: 暗黙知形式知化 × マルチエージェント、ターゲットセクター・銘柄数・回転率
2. **Team**: 運用責任者経歴、前職実績、コア人材バックアップ
3. **Edge**: 機関投資家ベンチマーク超過の構造的源泉（暗黙知の質、エージェント設計、データ）
4. **Track Record**: PoCバックテスト（IR・Sharpe・max DD・hit rate）、前職実績
5. **Risk Management**: VaR、ストレス、ファクター露出、コンセントレーション
6. **Capacity**: 戦略容量、流動性制約、運用残高拡大時のスタイル制約
7. **XAI / AI Governance**: 説明インフラ、モデルカード、第三者検証
8. **Fees**: 管理報酬・成功報酬・実績連動報酬（GPIF型アラインメント）
9. **Compliance**: 金商法登録ステータス、外部委託先、利益相反
10. **Terms**: 投資一任契約／プロ向け届出、最低投資額、ロックアップ、流動性
