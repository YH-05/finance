##### 論理性の軸への考え方

**定義**: 「与えられた企業情報に対し、どのCAラベルが妥当か / 妥当でないか」を再現性高く判定するための知識体系。dogma（ルール）と KB（パターン・Few-shot）で構成。

**これまでの構築方法**:
- AIレポート生成 → Yのフィードバック取得 → dogma/KB へ反映 のループでロジックを深化
- KB1 = 一般的な却下/採用ルール（ラベルが不適用となる構造的条件など）
- KB2 = 業界・ビジネスモデル別の典型パターン
- KB3 = 具体銘柄の Few-shot 事例

**達成できたこと**:
- 「明らかに弱い競争優位性主張」のフィルタリング（FM目線の機能）
- AIが Y の判定基準に近い形でCAラベルの当否を判定可能に
- ca_strategy パッケージで PoC として 395銘柄スケールの実行に到達

**直面している限界（飽和）**:
- フィードバックを重ねるほど追加ルールが細分化し、汎用性のある dogma 更新が出にくくなる
- Y からの差分情報も「もうほぼ言い尽くした」状態に近づいている
- 論理性を深めても **「どのCA仮説を採用すべきか」「採用したCA仮説をどれだけ強く信じるか」** は決まらない（ラベルの当否 ≠ 投資判断）

**今後の位置づけ**:
- 論理性の軸はこれ以上の深堀りを優先せず、現状のv1.0をフィルタ／参照知識として固定運用
- 判断の軸の構築に注力し、CA dogma は判断パイプラインの一構成要素として組み込む

##### 判断の軸への考え方

**定義**: 投資判断 = 「適用候補のCAから何を選ぶか」「CAGR をどこに置くか」「ITG 水準とそのスプレッドをどう評価するか」を **要素ごとに確信度を評価し、要素間でウェイトづけて統合する** プロセス。

**3要素の役割**:
| 要素 | 内容 | 確信度の独立性 |
|------|------|----------------|
| **CA選択** | 該当企業に適用可能なCAラベルの選定と、そのCAが生む競争優位の強度 | CA仮説の堅牢性（情報による裏付けの厚さ）で評価 |
| **CAGR予想** | 3年以上の長期成長率（Sales / Net Income / EPS） | CAの確信度とは独立に、需要環境・実行力など別軸で評価 |
| **ITG** | バリュエーションに織り込まれた長期成長率。CAGR との **スプレッド** が投資妙味のシグナル | ITG 水準そのもの（割高／妥当）と、スプレッドの解釈の両面で評価 |

**判断の軸に含まれる暗黙知（要抽出）**:
1. **情報の取捨選別基準**: 大量の決算・トランスクリプト・ニュースから、何を「CA仮説を支持する材料」と認め、何を捨てるか
2. **確信度の付け方**: 「確定的 / 強い / ゆるい / 推測」のどのレベルに置くか。同じ材料でも銘柄文脈で確信度が変わる
3. **CA確信度とCAGR確信度の切り分け**: 強いCAでも CAGR は不確実、ということがある（逆もある）
4. **CAGR-ITGスプレッドの読み方**: スプレッドが大きい = 良い、ではない。市場が織り込んでいないリスク／カタリストの両面解釈が必要
5. **要素間のウェイトづけ**: CA重視か / CAGR重視か / ITGスプレッド重視かは **銘柄ごと・アナリストごとに異なる**。これ自体が暗黙知の中核

**形式知化アプローチ**:
- 明示的ルール化（判断版 dogma）はやらない（論理性の軸と同じ飽和に陥る）
- **判断パスカタログ + RAG** で帰納的に再現
	- 判断パス = 「入力情報 → CA仮説候補 → 各仮説への納得度 → CAGR/ITG への落とし込み → BUY/SELL結論」の経路を一例ずつ記録
	- 属性タグ（業界・ビジネスモデル・成長フェーズ・カタリスト種別など）は **ルールではなく検索インデックス** として使う
	- 事例数が増えるほど RAG 精度が向上し、暗黙的に Y の判断パターンが再現される
- ca_strategy のスコアリングに AN 判断パス RAG を **並列統合**（CA dogma判定と並走させ複合スコア化）

**現在の進捗**:
- 8銘柄（ABBV, DASH, FCX, GEV, JPM, KR, MU, VZ）について 1銘柄あたり8仮説 = 64仮説の Q&A シート完成
- Y からの納得度回答収集中 → 回収後、64仮説への属性タグ付与 → 判断パスカタログのデータモデル詳細設計
